# Handy Art Reference Toolとは？使い方・料金・追加課金までわかりやすく解説

Handy Art Reference Toolは、手、頭部、足、胴体、動物の頭蓋骨などを3Dで回転させ、絵を描くときの資料として使えるアプリです。日本のApp Storeでは本体300円で販売されています。

「手のこの角度が分からない」「顔に横から光を当てたときの影を見たい」といった場面で、自分で鏡や写真を用意せず3Dモデルを好きな角度へ動かせます。ポーズだけでなく光源も調整できるため、形と陰影の両方を確認できるのが特徴です。

この記事では、2026年8月23日時点のApp Store公式情報をもとに、Handy Art Reference Toolがどんなアプリなのか、どう使うのか、本体300円だけで足りるのか、どんな人に向いているのかまで整理します。

## Handy Art Reference Toolとはどんなアプリ？

Handyは、イラストやデッサンのための3Dリファレンスツールです。

手や頭部などのモデルを回転し、普段は見えにくい角度から形を確認できます。手指や足のポーズを変えられるため、写真素材に欲しいポーズがないときでも自分で近い形を作れます。

光源は最大3つまで調整でき、方向、色、強さを変えられます。輪郭だけではなく「この角度から光が当たるとどこに影ができるか」を確認できるので、塗りの資料としても使えます。

モデルの材質や色も変更できます。肌のような質感だけでなく、反射の強さを変えながら立体感を確認できます。

そのためHandyは、**完成イラストを作るアプリではなく、描く前・描いている途中に形と光を確認するための参考資料アプリ**です。

## Handyはどうやって使う？

App StoreからiPhoneまたはiPadへインストールします。

アプリを開き、手、頭部など見たいモデルを選びます。画面上でモデルを回転し、必要に応じてポーズを変更します。

光源を追加すれば、正面光、逆光、斜め上からの光などを試せます。気に入った角度やライト設定は保存できるので、同じキャラクターを複数カット描くときにも使いやすくなります。

透明背景付きのスクリーンショットを書き出すこともでき、作画ソフト側へ参考画像として持っていく使い方もできます。

操作自体は直感的ですが、モデルは比較的写実寄りです。デフォルメ絵を描く場合は、そのままトレースするのではなく、自分の絵柄へ置き換える必要があります。

## Handyの料金について

日本のApp Storeでは本体300円です。

本体には手や頭部など主要なモデルが含まれています。追加購入としてFeet Modelsが300円、Animal Skull Packが300円です。

つまり「300円ですべてのモデルが使える」わけではありません。ただし、手や頭部の資料が目的なら本体だけでも十分使えます。

足を頻繁に描く人はFeet Models、動物やモンスターの骨格資料まで欲しい人はAnimal Skull Packを追加するという考え方が自然です。

月額サブスクリプションではないため、必要な追加パックだけ買えば固定費は増えません。

## Handyはどんな人に向いている？

Handyが向いているのは、手や顔の角度を描くたびに資料探しへ時間がかかる人です。

Web検索では「ほしい角度の手」が見つからないこともあります。Handyなら自分でモデルを回せるため、資料探しの時間を減らせます。

陰影の練習をしている人にも向いています。光源を変えながら頭部や胴体の影を見ることで、立体を意識した塗りの練習ができます。

一方、全身の複雑なポーズを自由に組みたい人には、より高機能な3Dポーズアプリの方が合う場合があります。Handyは特に手、頭、足、部分的な人体資料へ強いアプリです。

## まとめ｜Handyは「描きたい角度の資料がない」を300円から解決したい人向け

Handy Art Reference Toolは、手や頭部などの3Dモデルを自由に回し、ポーズや光の当たり方を確認できる作画資料アプリです。

本体は300円で、Feet ModelsとAnimal Skull Packはそれぞれ300円の追加購入です。最初から全部買う必要はなく、自分がよく描く部位に合わせて追加できます。

資料画像を毎回探す時間を減らしたいイラストレーターや、光と立体の練習をしたい人には使いどころが明確なアプリです。
