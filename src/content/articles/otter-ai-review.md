# Otter.aiとは？使い方・料金・無料版でどこまで議事録を作れるかを解説

Otter.aiは、会議や会話を録音・文字起こしし、AIで要約やアクション項目まで整理できるAIミーティングツールです。

Zoom、Microsoft Teams、Google MeetではOtter Notetakerを会議へ参加させ、録音と文字起こしを自動化できます。PCやスマートフォンで直接会話を録音したり、すでにある音声・動画ファイルを読み込んで文字起こししたりする使い方もできます。

現在のOtterは、単に音声を文章へ変換するだけではありません。会議中のスライドを取り込み、終了後に要約を作り、Otter AI Chatへ「何が決まった？」「次に誰が何をする？」と質問できます。

一方で、無料版には月間文字起こし時間やファイルImportなどの制限があります。有料版も個人向けのProとチーム向けのBusinessでは、増えるものがかなり違います。

この記事では、2026年8月24日時点のOtter公式情報をもとに、Otter.aiがどんなサービスなのか、実際にどう会議へ入れて使うのか、無料版でどこまで足りるのか、ProやBusinessへ上げる意味がどこにあるのかまで整理します。

## Otter.aiとはどんなサービス？

Otter.aiの中心にあるのは、会話を「あとから使える記録」に変えることです。

普通に会議を録音しただけでは、必要な内容を確認するときに音声を最初から聞き直さなければなりません。

Otterでは会話をリアルタイムで文字起こしし、話者を識別しながらTranscriptとして残します。録音音声とTextが同期しているため、文章の気になる部分から該当する音声へ戻って確認できます。

ここまでは一般的な文字起こしToolに近い機能です。

Otterの特徴は、そのTranscriptを会議後の仕事へつなげるところにあります。

会議が終わるとSummaryを生成し、重要な内容を短く確認できます。Virtual Meetingで共有されたSlideを自動CaptureしてNoteへ入れる機能もあり、「何を話していたときの資料なのか」をTranscriptと一緒に残せます。

さらにOtter AI Chatでは、記録されたConversationについて質問できます。

長い会議を最初から読み直す代わりに、「今回決まったことをまとめて」「Follow-up Emailを作って」「Action Itemを一覧にして」といった形で会議内容を再利用できます。

複数MeetingをまたいでAI Chatを使う機能もあります。

そのためOtterは、**文字起こしそのものを目的にするServiceというより、会議で発生した情報を記録し、あとから検索・要約・再利用できるMeeting Knowledgeへ変えるService**と考えると分かりやすいです。

## Otter.aiはどうやって使う？

使い方は、何を録音するかによって変わります。

オンライン会議ならOtter Notetakerを使う方法が中心です。

Google CalendarやMicrosoft CalendarをOtterへ接続すると、予定されているZoom、Microsoft Teams、Google Meetの会議へNotetakerを自動参加させられます。

NotetakerはMeeting Participantとして入り、会話を録音・文字起こしします。

自分がHostのMeetingだけでなく、Calendarに招待されている会議にも参加させられます。急に始まった会議なら、手動でNotetakerを追加することもできます。

会議中はWebやiOS・Android AppからTranscriptを追えます。

つまり「会議が終わってから録音FileをUploadする」のではなく、話している最中から文字起こしを確認できます。

ZoomについてはMac・Windows向けOtter Desktop Appを使い、Notetaker Botを参加させずPC側でMeeting Audioを録音する方法もあります。

対面MeetingやInterviewなら、PCまたはMobile DeviceのMicrophoneから直接録音できます。

すでに録音済みの音声・動画がある場合はFileをImportして文字起こしできます。

OtterはWebだけでなくiOS、Android、Desktop Appを用意しているため、オンライン会議専用ではありません。

PCではMeetingを管理し、外出先ではPhoneで対面会話を録音するという使い分けもできます。

## 会議にOtterを入れると何が自動化される？

Otter NotetakerをMeetingへ参加させると、まず録音とリアルタイム文字起こしが行われます。

会議中にすべてを手書きでNoteする必要が減るため、自分はConversationへ集中しやすくなります。

Virtual MeetingでSlideやScreenが共有されると、その内容をCaptureしてMeeting Noteへ追加する機能もあります。

これは単なるTranscriptより実用的です。

「この発言はどのSlideについて話していたのか」が分からなくなる問題を減らせるからです。

会議後にはAI Summaryが作られます。

全文を読み返さなくても、何について話したのかを先に把握できます。

さらにAI Chatを使えば、Transcriptを検索するだけでなく、自然な文章で内容を取り出せます。

たとえば1時間のMeetingで最後の10分だけ聞き逃した場合、録音を10分聞き直す以外に「最後に決まったAction Itemは？」と質問できます。

Follow-up EmailやMeeting Summaryの形式へ変換することもできます。

Otterを使う意味は、文字起こしの手間を減らすだけではありません。

**会議中にNoteを取る時間、会議後に録音を聞き返す時間、決定事項をもう一度整理する時間までまとめて減らす**ところにあります。

## Otter AI Chatは会議の内容をどう使える？

文字起こしが残っていても、長いMeetingほど必要な情報を探すのは大変です。

Otter AI Chatは、保存されたConversationを自然な言葉で検索・整理するための機能です。

「この会議で決まったことは？」
「担当者ごとのAction Itemをまとめて」
「顧客が懸念していた点は？」
「Follow-up Messageを書いて」

といった質問をできます。

重要なのは、一般知識を質問するChatbotというより、自分のMeeting Knowledgeを扱うためのAIだということです。

現在のOtterは、ChatGPTやClaudeなど外部AI Chat ToolからMeeting KnowledgeへAccessするためのMCP Serverも案内しています。

Otter内に溜まったMeetingを別のAI Workflowへ持ち込み、より深い分析へ使う方向にも広がっています。

会議を一度記録して終わりではなく、その情報を次の仕事へ再利用したい人ほどOtterの価値が出ます。

## 録音済みの音声や動画も文字起こしできる

OtterはLive Meetingだけでなく、すでに持っているAudio・Video FileのImportにも対応しています。

Interviewを録音してあとから文字起こしする。

過去のMeeting Recordingを読み込む。

動画素材の会話をText化する。

こうした用途にも使えます。

対応形式として公式HelpではMP3、AAC、WAV、M4A、WMAなどのAudioと、MP4、AVI、MOV、WMV、MPGなどのVideoが案内されています。

ただしFile ImportはPlan差が大きい部分です。

BasicではLifetimeで3 Files。

Proでは月10 Files。

BusinessではUnlimited Importが案内されています。

そのため大量の録音Fileをあとから処理したい人は、無料版の文字起こし時間だけを見て判断しない方がいいでしょう。

会議へNotetakerを入れるのが中心なのか、録音済みFileを大量に処理するのかで必要なPlanが変わります。

## Otter.aiの料金について

OtterにはBasic、Pro、Business、Enterpriseがあります。

Basicは無料です。

現在の公式Pricingでは、月300分のTranscription、1回のConversationあたり最大30分、Audio・Video File ImportはLifetimeで3件です。

Zoom、Microsoft Teams、Google MeetへのNotetaker、Live Transcription、Speaker Identification、Audio Playback、AI Chatなど基本機能を試せます。

Proは個人やSmall Team向けです。

月払いでは1Userあたり月16.99ドル、年払いでは月換算8.33ドルが通常価格として表示されています。

ProではIn-app Recordingが月1,200分、1Meetingあたり最大90分、File Importが月10件になります。

Unlimited Storage、Team Vocabulary、Taggable Speakers、Advanced Search・Export・Playbackなども追加されます。

Businessは中規模Team向けです。

月払いは1Userあたり月30ドル、年払いは月換算19.99ドルです。

BusinessではUnlimited MeetingsとIn-app Recordings、1Meeting最大4時間、Unlimited Audio・Video File Imports、3 Concurrent Meetings、Activity LogやUsage AnalyticsなどのAdmin機能が追加されます。

Enterpriseは個別見積もりです。

SSO、SCIM、Domain Capture、Enterprise向けSecurity、API・Webhooksなど、組織管理やSystem連携が必要な企業向けです。

料金だけを見るとBasicからBusinessまで大きな差がありますが、実際には「文字起こし精度が急に別物になる」というより、**使える時間、1Meetingの長さ、Import量、Team管理が段階的に増える**と考える方が分かりやすいです。

## 無料版でどこまで使える？

BasicでもOtterの基本的な使い方は確認できます。

Zoom、Teams、Google MeetへNotetakerを入れる。

リアルタイムでTranscriptを見る。

Speakerを識別する。

録音をPlaybackする。

AIでMeetingを整理する。

こうした流れを無料で試せます。

月300分なので、Meeting時間に直すと合計5時間です。

ただし1Conversationは最大30分です。

ここが無料版を判断するときに重要です。

月に数回、30分以内のMeetingを記録する程度ならBasicでも使えます。

一方、毎週1時間の定例会議がある場合、月間300分が残っていても1Meeting 30分の制限が先に問題になります。

また録音済みFileのImportはLifetimeで3件なので、Interview Recordingなどを継続的にUploadする用途には向きません。

無料版は「OtterのDemoしかできない」というほど狭くありません。

しかし仕事のMeetingを継続して記録する場合は、**月300分より1Meeting 30分とFile Import 3件の方が先に有料化の理由になる人も多い**でしょう。

## Proにする意味はどこにある？

個人利用なら、最初に検討しやすい有料PlanはProです。

Basicの1Meeting 30分が90分へ伸び、In-app Recordingは月1,200分になります。

一般的な1時間Meetingを最後まで記録したいなら、この差だけでも分かりやすいです。

月1,200分は20時間分なので、週に数回Meetingがある個人でも使いやすくなります。

File ImportもLifetime 3件から月10件へ変わります。

録音済みInterviewやMeeting Recordingを定期的に処理する人には大きな差です。

Unlimited Storage、Advanced Search・Export、Team Vocabularyなども追加されます。

特に固有名詞や業界用語を扱う場合、Vocabularyを整えながら長期的にMeeting Knowledgeを蓄積したい人に向きます。

逆に、30分以内のMeetingを月に数回しか記録しないならBasicのままでも足りる可能性があります。

Proへ上げる境目は「AI要約が欲しいか」ではありません。Basicでも基本的なAI機能を使えます。

**30分を超えるMeetingを記録したい、月5時間以上使いたい、録音Fileを継続的にImportしたい**という段階でProの意味が出ます。

## Businessにする意味はどこにある？

Businessは「Proよりもっと文字起こししたい個人」のためだけのPlanではありません。

Team運用の違いが大きくなります。

MeetingとIn-app RecordingがUnlimitedになり、1Meetingは最大4時間です。

同時に3つのMeetingへ参加できるため、組織内で複数のMeetingが重なる環境にも対応しやすくなります。

Audio・Video File ImportもUnlimitedです。

さらにActivity Log、Usage AnalyticsなどのAdmin機能が加わります。

Team全体でOtterを使う場合、誰がどの程度利用しているのかを管理しやすくなります。

そのため一人で週数回Meetingを記録するならProで十分なことが多いでしょう。

Businessが向いているのは、**Meetingが長い・多いだけでなく、複数人でOtterを共通のMeeting Knowledge基盤として使いたいTeam**です。

## 日本語で使う場合は何を確認したい？

Otter公式Pricingでは現在、AI Transcriptionの対応言語としてEnglish、Spanish、French、German、Japanese、Chineseが案内されています。

そのため日本語Meetingも利用対象に入っています。

ただし文字起こしToolは「日本語対応」と書かれているだけで実用性を判断しにくい分野です。

固有名詞。

社内用語。

複数人が重なって話すMeeting。

音質が悪い会議。

こうした条件で結果は変わります。

OtterにはVocabulary関連の機能もありますが、日本語中心で導入するなら、いきなり年払いするよりBasicで自分の実際のMeetingを録音して確認した方がいいでしょう。

特に議事録をそのまま社外へ出す用途では、AI Summaryだけを信用せず、Transcriptと録音を見ながら重要な内容を確認する必要があります。

## Otter.aiはどんな人に向いている？

Otterが向いているのは、会議そのものより「会議後の整理」に時間を取られている人です。

Meeting中にNoteを取り続ける。

終了後に録音を聞き返す。

議事録を書く。

決定事項を探す。

Follow-up Emailを作る。

こうした作業を一つのMeeting Recordから進められます。

特にZoom、Teams、Google Meetを頻繁に使う人はNotetakerによる自動参加との相性がいいでしょう。

InterviewやLectureの記録にも使えます。

一方、Meetingがほとんどなく、たまに短い音声を文字起こしするだけなら、OtterのMeeting Agent機能を使い切れない可能性があります。

また日本語中心なら、対応言語という表示だけで決めず、自分の会話で文字起こし結果を試すことが重要です。

Otterを選ぶ理由は「AIで文字起こしできるから」だけではありません。

**会議を録るところから、文字起こし、要約、検索、質問、Follow-upまで一つの流れにまとめたいか**を見ると、自分に必要か判断しやすくなります。

## まとめ｜Otter.aiは「文字起こし」より会議後の作業まで減らしたい人向け

Otter.aiは、MeetingやConversationを録音・文字起こしし、AI SummaryやAI Chatを使って内容をあとから活用できるAI Meeting Toolです。

Zoom、Microsoft Teams、Google MeetではNotetakerを会議へ参加させられ、Web、iOS、Android、Desktopからも利用できます。

Basicは無料で、月300分、1Conversation最大30分、File ImportはLifetime 3件です。

短いMeetingを時々記録するなら、まずBasicで十分試せます。

Proは1Meeting最大90分、月1,200分、File Import月10件となるため、1時間程度のMeetingを日常的に記録する個人には有料化の意味が出やすくなります。

BusinessはUnlimited Meetings、最大4時間、Unlimited File Imports、3 Concurrent Meetings、Admin機能などが加わり、TeamでMeeting Knowledgeを共有・管理する用途へ向いています。

Otterを検討するときは、文字起こしの有無だけを見なくて構いません。

Meeting中のNote、終了後の要約、決定事項の検索、Follow-upまで含めて、今どれだけ時間を使っているかを見る。

そこをまとめて減らしたいなら、Otter.aiを使う意味が見えてきます。
