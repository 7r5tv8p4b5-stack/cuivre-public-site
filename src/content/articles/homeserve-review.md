# ホームサーブはお得？住宅修理サブスクの料金・補償・解約を解説【2026年版】

「トイレが詰まった」「蛇口から水漏れした」「給湯器が故障した」。

住宅設備のトラブルは、いつ起こるか分かりません。しかも実際に故障してから修理業者を探すと、どこに頼めばいいのか分からず、料金がどのくらいになるのかも判断しにくいものです。

そんな住宅設備の故障に、月額・年額の定額料金で備えるのが**ホームサーブ**です。

ホームサーブは、住宅設備の故障トラブルが起きたときに、電話で修理を依頼できるサブスク型のサービス。2025年には「日本サブスクリプションビジネス大賞」でグランプリを受賞し、2026年7月には契約件数が40万件を突破しました。さらに同月、水まわり修理サービスに新しいライトプランを追加しています。

ただし、**「月660円から」とだけ見て申し込むのはおすすめできません。**

プランによって、

- 修理1回あたりの上限金額
- 修理できる範囲
- 年間の利用回数
- 対象となる住宅
- 契約期間
- 解約・自動更新

などが異なるからです。

## ホームサーブとは？

ホームサーブは、住宅設備の故障トラブルに定額料金で備える修理サービスです。

住宅設備が壊れたときに自分で修理業者を探すのではなく、ホームサーブへ連絡して修理を手配してもらいます。

対象となる設備はプランによって異なりますが、水まわり修理サービスでは、

- キッチンの水栓・排水口
- 洗面所・浴室の水栓・排水口
- 洗濯場の水栓・排水口
- トイレ・トイレタンク・水栓
- 屋外の水栓・給排水管

などが対象です。

2026年7月には水まわり修理サービスに「ライトプラン」が新設され、従来のエコノミー・ベーシックと合わせて3プランになりました。

また、ホームサーブは電力会社などのパートナー企業と連携して、地域ごとの住宅設備修理サービスも提供しています。そのため、申し込む際には**自分の地域でどのサービスが利用できるか**を確認する必要があります。


# ホームサーブの料金はいくら？

ここはかなり重要です。

2026年7月から始まった水まわり修理サービスでは、現在3つのプランが案内されています。

| プラン | 一括払い | 1か月あたりの目安 | 分割払い |
|---|---:|---:|---:|
| ライト | 7,920円/年 | 660円 | 790円/月 |
| エコノミー | 11,880円/年 | 990円 | 1,040円/月 |
| ベーシック | 19,080円/年 | 1,590円 | 1,670円/月 |

すべて税込です。

ただし、**この料金だけで比較するのは危険**です。

プランによって対象範囲や修理上限、利用回数が違うからです。


# ライト・エコノミー・ベーシックの違い

## ライトプラン

2026年7月に新設されたプランです。

一括払いなら年間7,920円、月額換算で660円。分割払いでは790円/月となっています。

屋内の給排水設備の故障トラブルに特化したプランで、ホームサーブは築浅の戸建て住宅や分譲マンションの所有者などにおすすめしています。

「大きな補償までは必要ないけれど、水まわりの突然のトラブルには備えたい」という人向けの位置付けです。

ただし、ライトプランは2026年7月15日から地域ごとに順次提供開始とされているため、**全国で同じタイミングで利用できるとは限りません**。


## エコノミープラン

一括払いは年間11,880円、月額換算990円。分割払いは1,040円/月です。

2026年7月のリニューアルで、修理上限金額が拡充され、**1回あたり最大30万円、利用回数制限なし**の新しい内容になったとホームサーブが発表しています。

一方、公式の現行プランページでは、1回あたり最大5万円・年2回までという内容も表示されているページがあります。

この差は、**提供地域・更新時期・プランページの適用条件を確認する必要がある重要なポイント**です。

そのため、申し込み時には自分の住所から案内される最新の契約条件を確認してください。


## ベーシックプラン

一括払いは年間19,080円、月額換算1,590円。分割払いは1,670円/月です。

対象範囲はエコノミープランより広く、

- キッチン
- 洗面所
- 浴室
- 洗濯場
- トイレ
- 屋外の水栓
- 屋外の給排水管

などが対象となります。

修理は**1回あたり最大30万円、回数制限なし**とされています。

ホームサーブは、特に築10年以上の戸建て住宅など、住宅設備のメーカー保証が切れている住宅に向くプランとして案内しています。


# 「月660円」は本当に安い？

年間7,920円なので、確かに月額換算660円は安く見えます。

ただし、ホームサーブの価値は**修理を一度も使わなかった場合にもあります**。

たとえば年間7,920円を払って、

> 「結局1年間、故障しなかった」

となれば、金額だけを見ると修理費用は発生していません。

一方、

> 「突然トイレが詰まった」
> 「水漏れが起きた」
> 「修理業者をどこに頼めばいいか分からない」

という状況になったとき、対象範囲内であれば修理費・部品代・出張費などが上限内でサービス料金に含まれる仕組みがあります。

つまりホームサーブは、

**「修理費を必ず安くするサービス」**

というより、

**「突然の住宅修理費と業者探しの不安を、定額料金で前払いしておくサービス」**

と考える方が分かりやすいでしょう。


# 修理費は本当に無料？

対象範囲内で、プランごとの上限金額までなら、修理費・部品代・出張費などがサービス利用料金に含まれるとFAQで案内されています。

ただし、**上限を超えた分は自己負担**です。

たとえば30万円が上限のプランで修理費用が33万円になった場合、

**33万円 − 30万円 = 3万円**

が追加負担となります。

そのため、

> 「加入していればどんな修理でも完全無料」

ではありません。

ここは契約前に必ず理解しておきたいポイントです。


# 本体交換は対象？

ここも注意が必要です。

ホームサーブは基本的に**修理・部品交換によって不具合を解消するサービス**です。

対象設備そのものを丸ごと交換して新品にするサービスではありません。

つまり、

「古いトイレだから新品のトイレに交換してほしい」

といった目的では利用できません。

修理で対応できる範囲なのか、設備そのものの買い替えが必要なのかを分けて考える必要があります。


# ホームサーブは24時間対応？

**修理受付は24時間365日です。**

トラブルが発生したときは、修理受付センターへ電話して依頼できます。

ただし、ここには重要な注意点があります。

**24時間365日「受付」＝24時間いつでも修理に来る、ではありません。**

ホームサーブ自身も、緊急駆け付けサービスではなく、訪問修理日は調整のうえ翌日以降になる場合があると案内しています。

「今すぐ来てほしい」という人は、別の緊急駆け付けサービスとの違いを理解しておきましょう。


# ホームサーブは誰でも申し込める？

誰でも申し込めるわけではありません。

ホームサーブ公式サービスでは、戸建て住宅または分譲マンションの所有者本人とその家族が対象です。

**賃貸住宅に住んでいる人や、住宅を営利目的で使用している場合は申し込めません。**

また、サービスエリア外では申し込めないため、住所による確認も必要です。


# ホームサーブの契約期間と解約

サービス利用期間は基本的に**12か月**です。

契約満了までに更新しない旨の申し出がなければ、さらに12か月間自動更新されます。

つまり、

**1年だけ利用するつもりなら、解約手続きを忘れないこと**

が重要です。

また、利用開始前に解約した場合は全額払い戻しされますが、利用開始後の解約については、一括払いか分割払いかによって扱いが異なると公式FAQに記載されています。

さらに引っ越しの場合、提供エリア内なら旧住所の契約を終了して新住所で再契約、エリア外へ引っ越す場合は契約終了となりますが、未経過分の利用料金は返金されません。


# ホームサーブと火災保険は何が違う？

これは検索する人がかなり気になるところでしょう。

ホームサーブと火災保険は、似たように「もしもの住宅トラブルに備える」ものですが、仕組みが違います。

ホームサーブは、

**契約したプランの対象設備を修理するサービス**

です。

一方、火災保険は一般に、

**事故や損害に応じて保険金が支払われる仕組み**

です。

そのため、

「火災保険に入っているからホームサーブはいらない」

とも、

「ホームサーブに入れば火災保険はいらない」

とも単純には言えません。

自分の火災保険の補償内容と、ホームサーブの対象範囲を確認して判断するのが安全です。


# ホームサーブのメリット

## 1. 修理業者を自分で探す必要がない

住宅設備が突然壊れたとき、一番困るのが「どこに頼めばいいのか分からない」という問題です。

ホームサーブでは、電話一本で修理を手配してもらえます。

これは修理費そのものとは別の大きなメリットです。


## 2. 修理費用の予測がしやすい

定額料金を支払っているため、対象範囲内の修理なら突然大きな修理費が発生するリスクを抑えやすくなります。

もちろん上限超過分などは自己負担ですが、「いくらかかるか分からない」という不安を小さくできるのが特徴です。


## 3. 住宅設備の故障にまとめて備えられる

プランによって水まわりの複数設備を対象にできます。

ベーシックプランなら屋外の給排水管まで対象です。


## 4. 2026年もサービスを拡張している

2026年7月にはライトプランを追加し、水まわり修理サービスを3プランへ拡充しました。

さらに2026年7月初旬には契約件数40万件を突破したと発表しています。

単なる昔からあるサービスではなく、現在もサービス内容を更新している点は注目できます。


# ホームサーブの注意点・デメリット

## 1. 「月660円」だけでは判断できない

最も重要です。

ライト、エコノミー、ベーシックで、

**料金・対象範囲・修理上限・利用回数**

が違います。

さらに地域によって提供プランが異なる場合があります。


## 2. 上限を超えた分は自己負担

30万円までのプランでも、30万円を超えれば差額は自己負担です。


## 3. 本体交換は基本的に対象外

修理サービスなので、設備を新品へ買い替えるためのサービスではありません。


## 4. 緊急駆け付けサービスではない

24時間365日受付ですが、修理訪問は翌日以降になる場合があります。


## 5. 契約は自動更新

解約しない限り12か月単位で自動更新されます。


# ホームサーブの評判は？

ホームサーブについては、公式サイトに利用者の声が掲載されています。

「訪問時間を事前に教えてもらえてスムーズだった」「丁寧な対応や分かりやすい説明で安心した」といった声が紹介されています。

ただし、これらは**ホームサーブ公式サイトが掲載している利用者の声**です。

第三者情報としては、PRESIDENT Onlineがホームサーブの運営会社を取材し、住宅修理サブスクの仕組みや顧客満足度、契約更新率などを紹介しています。

また、リフォーム産業新聞も、2025年12月時点で会員数32万人に達していたことや、サブスク大賞2025でグランプリを受賞したことを報じています。

一方で、「みん評」では現在ホームサーブの口コミが**0件**でした。

そのため、

> 「口コミサイトで大量の利用者が高評価しているサービス」

とまでは言えません。

現状では、**公式発表・第三者メディアの取材・受賞実績などは確認できる一方、独立した口コミデータはまだ十分ではない**

という評価が妥当でしょう。


# ホームサーブは本当にお得？

ここは「何をお得と考えるか」で変わります。

### 修理費用の突然の出費を避けたい

→ **相性がいい**

### 修理業者を探す手間を減らしたい

→ **相性がいい**

### 築10年以上の住宅に住んでいる

→ **検討価値が高い**

### 一度も故障しなければ損に感じる

→ **慎重に比較したい**

### 火災保険で十分な補償がある

→ **補償内容を確認してから判断**

### 賃貸住宅に住んでいる

→ **公式の対象外**

### 緊急時にすぐ来てほしい

→ **緊急駆け付けサービスとの比較が必要**

つまりホームサーブは、

**「修理費を安くするためだけのサービス」**

というより、

**「突然の住宅設備トラブルに備えて、費用と業者探しの不安をまとめて減らすサービス」**

と考えるのが近いでしょう。


# ホームサーブの申し込み方法

まず、自分の地域で利用できるホームサーブのサービスを確認します。

ホームサーブでは、全国一律の単一プランだけでなく、電力会社などのパートナー企業と連携した地域別サービスも提供しています。

そのうえで、

1. 対象エリアを確認
2. 対象となる住宅・設備を確認
3. プランを選択
4. 料金・利用条件を確認
5. 申し込み

という流れになります。

特に申し込み前には、

**「自分の住所でどのプランが利用できるか」**

を確認することをおすすめします。


# ホームサーブについてよくある質問

### ホームサーブは何のサブスクですか？

住宅設備の故障トラブルに備える定額制の修理サービスです。

水まわりや電気設備など、プラン・地域に応じた住宅設備の修理を受けられます。

### 月額はいくらですか？

2026年7月に始まった水まわり修理サービスのライトプランは、年間7,920円の一括払いで月額換算660円です。

エコノミーは月額換算990円、ベーシックは1,590円です。

### 修理は無料ですか？

対象範囲内でプランごとの上限金額までなら、修理費・部品代・出張費などがサービス利用料金に含まれます。

ただし、上限を超えた分は自己負担です。

### 何回でも修理できますか？

プランによって異なります。

ベーシックは回数制限なし。エコノミーについては、現在の公式プランページに年2回までと記載されている一方、2026年7月の新プラン発表では利用回数制限なしへリニューアルしたと案内されています。

そのため、**申し込み時に地域別ページと最新の利用規約を確認することが重要です。**

### 24時間365日対応ですか？

修理の受付は24時間365日です。

ただし緊急駆け付けサービスではなく、訪問日は調整されます。

### 賃貸でも利用できますか？

ホームサーブ公式の定額制修理サービスでは、賃貸住宅は申し込み対象外です。戸建て住宅または分譲マンションの所有者本人とその家族が対象です。

### 火災保険とは違いますか？

違います。

火災保険は一般に損害に応じた保険金が支払われる仕組みですが、ホームサーブは契約プランに応じて対象設備を修理するサービスです。


# 結論：ホームサーブは「修理費」だけでなく「突然の不安」に備えるサブスク

ホームサーブを調べて分かったのは、**「月660円から」という料金だけではサービスの価値を判断できない**ということです。

料金が安いライトプランから、屋外の給排水管まで対象にするベーシックプランまで、住宅の状態や必要な補償範囲に応じて選択肢があります。

一方で、

- 修理上限がある
- 対象外の設備・作業がある
- 本体交換は対象外
- 緊急駆け付けではない
- 12か月単位で自動更新
- 地域によって利用できるプランが異なる

といった条件もあります。

そのため、

**「安いから入っておこう」**

ではなく、

**「自分の住宅で起こりそうな故障を、どこまでカバーしたいか」**

で選ぶのがおすすめです。

特に築年数が経過した住宅に住んでいて、突然の修理費や業者探しに不安があるなら、検討する価値のあるサービスでしょう。

逆に、賃貸住宅に住んでいる人、火災保険などですでに十分な補償を確保している人、緊急駆け付けを求めている人は、別の選択肢と比較した方がいいでしょう。

**ホームサーブは「修理を安くするサブスク」というより、「住宅設備の突然のトラブルに備えるサブスク」。**

この視点で料金と補償範囲を比較すると、自分に必要なサービスなのか判断しやすくなります。
