# Bolt.newとは？AIでWebサイト・アプリを作る方法・料金・無料版の限界を解説

Bolt.newは、作りたいWebサイトやWebアプリを自然な言葉で伝えると、AIがコードを書き、実行し、公開まで進めてくれるブラウザ型のAI開発サービスです。

「ランディングページを作って」のような小さな依頼から、データベースを使う業務ツールやWebアプリまで、同じ画面で会話しながら作れます。開発環境を自分のPCへ用意しなくても、ブラウザ上でコード生成・プレビュー・修正・ホスティングまで進められるのが特徴です。

この記事では、2026年8月24日時点のBolt公式情報をもとに、Bolt.newがどんなサービスなのか、実際にどう作るのか、無料版の100万Tokenでどこまで試せるのか、Proへ月25ドル払う意味がどこにあるのかまで整理します。

## Bolt.newはどんなサービス？

Bolt.newは、AIにコードの一部を書いてもらうツールというより、Web開発環境そのものをAIと一体化したサービスです。

作りたいものを文章で説明すると、Boltが必要なファイルを作成し、ブラウザ上でアプリを起動します。生成結果はすぐPreviewでき、気になるところをそのままAIへ伝えて直していきます。

たとえば「美容院の予約サイトを作って」と依頼した後に、「予約フォームを追加」「管理者だけ予約一覧を見られるように」「トップをもう少し落ち着いたデザインに」と続けられます。

画面だけを生成するサービスではありません。BoltにはWeb HostingとDatabaseが用意されており、Freeを含む各Planでサイト公開とデータ保存を始められます。コードも確認・編集できるため、AIへ任せるだけでなく必要な部分を人間が直接触れます。

通常のWeb開発では、Node.js、Package、Editor、Database、Hostingなどを準備する必要があります。Boltなら、最初のPromptから動く画面までをブラウザ内で進められます。

一方、アプリが大きくなるほどAIが毎回読むProject Contextも増え、Token消費が大きくなります。Bolt自身も、Token利用の多くはProject File SystemをAIへ同期するために使われ、Projectが大きいほど1 MessageあたりのToken消費が増えると説明しています。

つまりBolt.newは、**自然言語からすぐWebアプリを動かせる速さと、普通のコードとして修正できる自由度を両立したAI App Builder**です。

## Bolt.newではどうやって作る？

最初はBolt.newを開き、作りたいものを文章で入力します。

単に「TODOアプリ」と書くより、誰が使うのか、必要な画面、保存したいデータ、見た目などをまとめて伝えた方が初期生成は安定します。

生成が始まると、Boltがコードを書き、Packageを用意し、Previewを表示します。ここから実際の画面を見ながら修正します。

Databaseが必要ならBolt Databaseを使えます。FreeでもUnlimited Databasesが含まれるため、単なる静的サイトだけでなく、データを持つWebアプリを試せます。

完成したらBolt Hostingへそのまま公開できます。Freeでも公開URLを持てますが、サイトにはBolt Brandingが残ります。独自ドメインを使いたい場合やBrandingを外したい場合はPro以上が必要です。

この流れなら、コードを書いた経験が少なくても「作る→動かす→直す→公開する」まで一つのサービス内で確認できます。

逆に既存の大規模Repositoryを細かく保守することが主目的なら、CodexやCursorのようなCoding Agent / IDE型の方が自然な場合があります。

## Bolt.newの料金について

Bolt.newにはFree、Pro、Teams、Enterpriseがあります。

Freeは0ドルです。1日300,000 Token、月1,000,000 Tokenまで利用できます。Public / Private Project、Website Hosting、Unlimited Databasesが含まれます。

Freeでも実際にWebサイトを作って公開できるため、Boltの操作感を確認するだけなら有料契約は必要ありません。

Proは月25ドルです。Daily Token Limitがなくなり、月10,000,000 Tokenから利用できます。Bolt Brandingの削除、Private Sharing、Custom Domain、SEO Boosting、より大きなDatabase Capacity、Database Provider選択、AI Image Editingなどが加わります。

有料Subscriptionの未使用Tokenは、Active Subscriptionを維持していれば翌月まで繰り越せます。

Teamsは月30ドル/Memberです。Proの機能に加え、Centralized Billing、Team-level Access Management、Admin Control、Organization内共有、Private NPM Registry、Design System Knowledgeなどチーム開発向け機能が増えます。

Enterpriseは個別見積もりです。

Tokenは「AIへ送れるメッセージ数」ではありません。同じ一回の依頼でも、小さなProjectと大きなProjectでは消費量が違います。AIが参照するFile Systemが増えるほどTokenを使うためです。

## 無料版からProにする意味はどこにある？

Freeの月100万Tokenは、Boltを試すには十分ですが、本格的なアプリを何度も修正すると不足しやすくなります。

特にProjectが大きくなると、一回の変更でも多くのContextをAIへ渡す必要があります。

そのためFreeは「簡単なサイトを一本作ってみる」「MVPの初期画面を試す」といった用途に向いています。

Proへ移る一番分かりやすい理由は、単純にTokenが10倍以上になることです。ただ、それだけではありません。

実際に顧客へ見せるサービスなら、Custom DomainとBolt Branding削除が重要になります。Freeの公開URLで検証した後、独自ドメインを付けて正式公開する段階でProへ上げる流れが自然です。

Database容量やWeb Request上限も増えるため、利用者が増えたアプリではHosting側の差も効いてきます。

月25ドルを払う意味が出るのは、**作ったものを試作品から自分のサービスとして公開する段階**です。

## Bolt.newはどんな開発に向いている？

Boltが向いているのは、新しいWebサイトやWebアプリを短期間で形にしたい人です。

Landing Page、予約システム、顧客Portal、簡単なSaaS、社内Toolなど、ブラウザで使うサービスは特に相性があります。

コード経験がなくても始められますが、開発者が高速なPrototype環境として使うこともできます。AIが作ったコードを直接確認できるので、「ノーコードで作ったため後から触れない」という状態にはなりません。

一方、大規模な既存RepositoryのIssueを順番に直す、Terminal中心で開発する、Pull Request Reviewまで自動化するといった用途ではCoding Agent型の方が合います。

また、BoltはWeb開発が中心です。ネイティブiOS / Androidアプリを直接XcodeやAndroid Studio向けに完成させるサービスとして考えると目的がずれます。

## まとめ｜Bolt.newはWebアプリの最初の一歩から公開までを速くしたい人向け

Bolt.newは、自然言語からWebサイト・Webアプリを生成し、Database、Hosting、公開までブラウザ上で進められるAI開発サービスです。

Freeでも月100万Token、Website Hosting、Unlimited Databasesを利用できます。Proは月25ドルで月1000万Tokenから。Custom Domain、Bolt Branding削除、より大きなHosting / Database枠などが加わります。

無料版はBoltが自分の開発に合うか確認するには十分です。実際に何度も機能を追加し、独自ドメインで自分のサービスとして公開したくなった段階でProの意味が大きくなります。
