# Gammaとは？AIプレゼン作成の使い方・料金・無料版でどこまでできるかを解説

Gammaは、テーマや文章を入力すると、構成、文章、レイアウト、画像までまとめて生成し、プレゼンテーションやドキュメント、Webサイトなどを作れるAIデザインサービスです。

「AIでPowerPointを作るサービス」と紹介されることが多いですが、現在のGammaで作れるものはスライドだけではありません。SNS向けコンテンツ、グラフィック、Webサイトまで同じ編集環境で作成でき、作った資料をPPTXやPDFへ書き出すこともできます。

さらに2026年には、複数の資料を渡して内容を相談しながら構成を作るCreate with Agentも加わり、単純な「テーマを入れて一発生成するツール」から、AIと内容を詰めながら成果物を作る方向へ広がっています。

この記事では、2026年8月24日時点のGamma公式情報をもとに、Gammaが実際に何をしてくれるのか、どうやって資料を作るのか、無料版でどこまで試せるのか、有料Planにする意味がどこから出るのかまで整理します。

## Gammaはどんなサービス？

Gammaの一番分かりやすい特徴は、資料作成の最初に「白紙のスライド」を見なくていいことです。

通常のPowerPointでは、内容を考えたあとにSlideを追加し、TitleやText Boxを置き、画像を探し、Layoutを整える必要があります。

Gammaでは、まず伝えたい内容を渡します。

一文のIdeaから始めることもできますし、自分で作ったOutlineをPasteしたり、既存のPDFやPowerPointをImportしたりすることもできます。

そこからAIが内容をCard単位に分け、文章、構成、Visualを含む形へ整えます。

Gammaでは一般的なPresentationの「Slide」に近い単位をCardとして扱います。

生成後もCardを追加・削除し、文章を書き換え、LayoutやTheme、画像を変更できるため、AIが出した最初の結果をそのまま使う必要はありません。

ここが画像生成AIで「プレゼンっぽい画像」を作る場合との大きな違いです。

Gammaで作ったものは編集可能なDocumentとして残ります。

さらにAIによる書き換え、Layout変更、画像生成、翻訳などを編集途中でも使えるため、「最初だけAI、その後は全部手作業」になりにくい設計です。

現在のGammaはPresentationだけでなく、Document、Website、Social Media Content、Graphicsにも対応しています。

たとえば同じ企画内容でも、社内説明用ならPresentation、読み物として渡すならDocument、公開用ならWebsite、SNS告知ならSocial Contentというように、目的に応じてOutputを変えられます。

Gamma公式は20以上のAI Modelを組み合わせていると案内しており、Text、Image、Designを一つのModelだけで処理するServiceではありません。

つまりGammaは、**PowerPointの操作をAIで自動化するだけではなく、伝えたい内容を渡すところから、構成・Visual・公開形式まで一つの制作環境で整えるAIデザインパートナー**として見る方が分かりやすいサービスです。

## Gammaはどうやって使う？

GammaはBrowserから利用できます。

新しく作る場合は、Ideaから生成する方法、既存文章をPasteする方法、Templateから始める方法、FileやURLをImportする方法などがあります。

何も資料がないなら、まずTopicを入力してOutlineを作らせるのが簡単です。

すでに文章や企画書があるなら、AIに内容まで考え直させるより、元のTextを渡してVisual化や構成整理を任せる方が意図を保ちやすくなります。

PDFやPPTXをImportできるため、既存資料をGammaへ持ち込んで作り直すこともできます。

生成されたあとがGammaの本番です。

Themeを変更したり、CardごとにLayoutを変えたり、文章を短くしたり、画像を差し替えたりしながら仕上げます。

AIへ編集を頼むこともできるため、「この部分をもっと簡潔に」「別のVisualにして」といった修正を、全部自分で配置し直さず進められます。

完成した内容はGamma上でLink共有できます。

Presentationならそのまま発表できますし、PDF、PPTX、PNG、Google SlidesへExportすることもできます。

PowerPointへ持ち出せるので、「AIで下地を作るところだけGamma、社内Templateへの最終調整はPowerPoint」という使い方もできます。

一方、Gamma上で公開する方が便利な場合もあります。

Websiteとして公開すればHostingされたPageとして共有でき、ProではCustom Domainも利用できます。

資料作成Toolとして始めても、社外公開用の簡易Pageまで同じ内容から作れるのがGammaの広さです。

## Create with Agentは普通のAI生成と何が違う？

2026年のGammaを見るうえで押さえておきたいのがCreate with Agentです。

従来のAI生成では、PromptやOutlineを渡し、Gammaがそこから一気に内容を作る使い方が中心でした。

Create with Agentでは、AI Agentと会話しながら成果物を作ります。

PDF、Document、Slide Deck、Website、Image、既存Gammaなど複数のSourceを渡し、Agentが内容について質問しながらOutlineを一緒に整え、その後PresentationやDocument、Social Postを生成します。

たとえば「この3つの調査資料から経営会議用のPresentationを作りたい」という場合、単に3Fileを要約してSlideへ流し込むのではなく、誰に何を伝えるのかをAgentと詰めてから構成を作れます。

資料の内容そのものが重要な仕事では、この違いが大きくなります。

AIに見栄えだけ任せたいなら通常のGenerateでも十分です。

複数Sourceを統合する、構成を相談する、情報の取捨選択までAIと進めるならAgentの方が向いています。

Create with AgentはPlus、Pro、Ultra、Teamなどの有料Workspaceで利用できる機能で、現在はLab機能として提供されています。

そのためGammaは、単に「PromptからSlideを出すAI」だけでなく、**資料の内容を整理する段階からAIと共同作業するTool**へ広がっています。

## Gammaの料金について

Gammaには個人向けとしてFree、Plus、Pro、Ultraがあります。

Freeは0円で始められ、登録時に400 AI Creditsが付与されます。

Freeでは一つのPromptから最大10枚のSlideを生成でき、Presentation、Document、Website、Social、Imageなど基本的な作成機能を試せます。

PDFやPPTXのImport、PDF・PPTX・PNG・Google SlidesへのExportもFreeから利用できます。

ただしFreeの400 Creditsは毎月補充されるものではありません。

使い切った場合はReferralで追加Creditsを得るか、有料PlanへUpgradeする必要があります。

PlusではAI Creationが日常利用の範囲でUnlimitedになり、Gamma Brandingを削除でき、Advanced Image Modelなどが利用できます。

また月1,000 Creditsが付与され、AgentやAIによるCard追加などCredit対象のPremium AI機能へ使えます。

Proでは月4,000 Creditsになり、Premium Image Model、Custom BrandingとFont、詳細なAnalytics、高度な共有機能、Custom Domain、API Accessなどが加わります。

Ultraは月20,000 Creditsで、最先端のText・Image・Video ModelへのAccess、より多くのCustom Domain、新機能へのEarly Accessなどが中心です。

有料Planの料金額は月払い・年払い、地域、表示通貨によって変わるため、契約時にはGamma公式Pricing画面の表示を確認するのが確実です。

重要なのは、現在のGammaでは「有料Plan＝すべてのAI操作が完全無制限」という意味ではないことです。

標準的なAI Creationは有料PlanでUnlimitedですが、Agent、高度なModel、APIなどPremium機能ではCreditsを使います。

## GammaのAI Creditsはどう使われる？

GammaのCreditsは、AI機能の一部を利用するときに消費されます。

Freeでは基本的なAI操作もCreditsを使い、最初にもらった400 Creditsは自動ではRefreshされません。

有料Planでは仕組みが変わります。

通常のPresentation生成や標準ModelによるImage生成などはPlan内のAI Creationとして利用でき、CreditsはAgent、AIによるCard追加、Ultra Model、APIなどPremiumな処理で使われます。

そのためPlusへ入ったあと、Presentationを一つ生成するたびに必ず月1,000 Creditsが大きく減る、という考え方ではありません。

Credit消費量は処理内容、使うAI Model、生成する内容の長さや複雑さによって変わります。

画像生成では実行前にModelごとのCredit Costを確認できます。

有料PlanのCreditsは毎月Refreshされ、未使用分はPlanの月間付与量の2倍まで繰り越せます。

たとえばPlusなら通常1,000 Credits / monthなので、最大2,000 Creditsまで保持できます。

足りなくなった有料Userは追加Creditsを購入できます。

現在は1,500 Creditsを6ドルで追加でき、Auto-Rechargeも設定できます。

Gammaを頻繁に使う場合は、「何枚Presentationを作れるか」だけを見るより、自分がAgentやPremium Modelをどの程度使うかでPlanを考える方が実際の利用量に近くなります。

## 無料版でどこまで使える？

Gammaは、無料版でも「AIプレゼンが自分に合うか」を判断するところまでは十分試せます。

最大10枚のSlideを一度に生成でき、Presentation以外のDocumentやWebsiteも作れます。

ImportとExportもFreeから使えるため、作った資料をPPTXへ出してPowerPointで確認するところまで課金せず試せます。

そのため、最初からPlusへ入る必要はありません。

Freeでまず一つ、自分が実際に使うテーマの資料を作ってみる方がGammaの価値を判断しやすいです。

無料版からPlusへ移る意味が出やすいのは、Gammaを仕事の資料へ継続的に使い始めたときです。

FreeのStarter Creditsは補充されないため、AIを何度も使えばいずれ制限に当たります。

さらに共有・Exportした資料からGamma Brandingを外したい、Advanced Image Modelを使いたい、Create with Agentで複数資料からPresentationを作りたい、といった用途もPlusへ移る理由になります。

Proは「Gammaを使う頻度」だけではなく、Brandingと運用面が必要になった人向けです。

会社独自のFontやBrandを適用したい、公開した資料のAnalyticsを詳しく見たい、独自DomainでSiteを公開したい、APIからGamma生成を自動化したい、といった段階でProの意味が出ます。

UltraはさらにHeavy User向けです。

最新の高度なAI Modelを積極的に使い、月4,000 Creditsでは足りないほどAgentやPremium生成を使う場合に検討するPlanです。

Free → Plusは「Gammaを継続利用するか」、Plus → Proは「仕事のBrand・分析・自動化まで任せるか」、Pro → Ultraは「高度なAIを大量に使うか」と考えると選びやすくなります。

## PowerPointの代わりになる？

Gammaを検討するとき、「PowerPointをやめられるのか」は気になるところです。

資料をゼロから作る速さだけを見ると、Gammaの方が楽な場面はかなりあります。

文章からOutlineを作り、Designまでまとめて生成できるため、社内共有資料、企画のたたき台、営業資料の初稿などは短時間で形にできます。

Gamma上でそのままPresentationし、Link共有するならPowerPointを使わず完結することもできます。

一方、会社指定のPowerPoint Templateを厳密に使う、Slide上の細かな配置をPixel単位で調整する、複雑なAnimationを組む、といった作業ではPowerPointの方が自由です。

GammaはPPTXへExportできるので、どちらか一つに決める必要はありません。

Gammaで構成とDesignの初稿を作り、最後だけPowerPointで仕上げる使い方もできます。

逆に既存のPPTXをGammaへImportして、AIで見直すこともできます。

Gammaを「PowerPointの競合」とだけ考えるより、**PowerPointで一番時間がかかっていた白紙から初稿を作る工程をAIへ任せるTool**として見ると使いどころが分かりやすくなります。

## Gammaはどんな人に向いている？

Gammaが特に向いているのは、伝えたい内容はあるのに、資料の構成やDesignで時間を使っている人です。

営業資料、企画書、社内説明、講義資料などを頻繁に作る人なら、Outlineから見栄えのする初稿まで一気に作れるだけでも作業時間を減らせます。

Designが苦手な人にも向いていますが、Designができる人にも使い道があります。

AIでたたき台を作り、必要な部分だけ自分で整えれば、毎回Layoutをゼロから作る必要がありません。

またPresentation以外も同じ環境で作りたい人には便利です。

資料の内容をWeb Pageとして公開したり、SNS用Contentへ展開したりできるため、一つの企画を複数形式へ展開する仕事と相性があります。

一方、PowerPointの細かな操作そのものが重要な仕事では、Gammaだけで完全に置き換える必要はありません。

また月に一度簡単な資料を作る程度なら、Freeで足りる可能性もあります。

Gammaを選ぶ基準は、AIで「きれいなSlideが出るか」だけではありません。

**構成を考える、文章を整える、画像を探す、Layoutを作るという資料制作の前半をどれだけ短くできるか**が、自分の仕事にとって価値になるかを見る方が判断しやすいです。

## まとめ｜Gammaは資料のデザインより「初稿を作るまで」を短くしたい人に向いている

Gammaは、Ideaや既存文章からPresentation、Document、Website、Social Content、Graphicsなどを作れるAIデザインサービスです。

Freeでも最大10枚のSlide生成、PDF・PPTX Import、PPTX・PDF・PNG・Google Slides Exportまで試せます。

Plusでは継続的なAI Creation、Gamma Branding削除、Advanced Image Model、Create with Agentなどが使いやすくなり、Gammaを日常の資料作成へ取り入れる段階で意味が出ます。

ProではCustom Branding、Analytics、Custom Domain、APIなどが加わり、個人の資料作成Toolから会社やWorkflowの一部として使う方向へ広がります。

Gammaの強みは、PowerPointより細かく編集できることではありません。

何を伝えるかを渡したあと、構成、文章、Visual、Layoutまで含む最初の完成形を短時間で作り、必要ならPowerPointへ持ち出して仕上げられることです。

資料作成で一番時間を使っているのが「白紙からそれなりの初稿にするまで」なら、Gammaを使う意味はかなり分かりやすいでしょう。
