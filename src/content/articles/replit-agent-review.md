# Replit Agentとは？Agent 4の使い方・料金・Lovableとの違いを考える前に知りたい特徴

Replit Agentは、作りたいアプリやWebサイトを自然な言葉で伝えると、設計、コード作成、データベース、テスト、公開まで進めてくれるAI開発エージェントです。

Replitはもともとブラウザ上の開発環境として知られていましたが、現在は「コードを書く場所」に加えて、Agentが複数の作業を並列で進めるAI開発プラットフォームへ広がっています。

この記事では、2026年8月24日時点の公式情報をもとに、Replit Agent 4がどんな仕組みなのか、実際にどう使うのか、CoreとProの料金、Effort-Based Pricingで何にお金がかかるのかまで整理します。

## Replit Agentはどんなサービス？

Replit Agentは、アプリ開発を「AIにコードを書いてもらう」だけで終わらせないサービスです。

ユーザーが作りたいものを伝えると、必要なファイルを作成し、データベースや認証を設定し、エラーが出れば自分で修正しながらアプリを完成へ近づけます。

2026年3月に公開されたAgent 4では、この考え方がさらに強くなっています。

Agent 4は、一つのチャットで順番に作業するだけではなく、複数の作業を並列で進められます。

たとえば認証、データベース、バックエンド、フロントエンドデザインを別々に進め、結果をまとめてアプリへ反映できます。

Coreでは最大2 Parallel Agents、Proでは最大10 Parallel Agentsが利用できます。

デザイン面でも、Agent 4はInfinite Canvas上で複数のデザイン案を作成し、気に入ったものをアプリへ反映できます。単にコード生成だけでなく、UI案を並べて比較する作業までエージェントへ任せられます。

ReplitにはデータベースとDeploy環境も組み込まれています。

そのため「Agentでコード生成→別のクラウドへ移動→DBを設定→Deploy」という工程を別サービスへ分けず、同じWorkspace内で進められます。

Web Searchも利用でき、Agentは必要に応じて最新情報を調べながら作業できます。

複雑な依頼ではPlan Mode、Extended Thinking、強力なモデルなどを使い、最初に実装計画を作ってから進められます。

つまりReplit Agentは、**AIコード補完ツールではなく、開発環境・データベース・ホスティングまで持ったReplit上で、実際のソフトウェア開発工程をまとめて担当するエージェント**です。

## Replit Agentではどうやってアプリを作る？

最初はReplitで新しいProjectを作成し、Agentへ作りたいものを説明します。

「家計簿アプリを作って」だけでも始められますが、誰が使うのか、必要な画面、保存するデータなどを詳しく伝えるほど初期構成は明確になります。

Agentは必要なファイルを作り、実行結果を確認しながら修正します。

機能を追加したい場合は、そのままチャットで依頼します。

簡単な変更なら通常のAgentで十分ですが、複雑な機能ではPlan Modeを使い、変更内容を確認してから実装させることもできます。

複数の独立した作業がある場合はParallel Agentsが便利です。

たとえば一つのAgentに決済画面、別のAgentに管理画面、別のAgentにテスト修正を任せ、同時に進められます。

ReplitはBrowser上のIDEでもあるため、AIへすべて任せる必要もありません。

Agentが作ったコードを直接編集したり、TerminalでCommandを実行したり、人間が途中から細かく修正できます。

完成したらReplit上からDeployできます。

Starterでも1つのLive Projectを公開できます。Core / Proではより多くの本番利用やRegion選択などが可能です。

この「AIが作る環境」と「人間が普通にコードを書く環境」が同じ場所にあることがReplitの特徴です。

## Replit Agentの料金について

現在の基本PlanはStarter、Core、Pro、Enterpriseです。

Starterは無料です。

Daily Agent Creditsがあり、Built-in Database、1つのLive Projectなどを使えます。Agentを試して簡単なアプリを作る用途なら無料から始められます。

Coreは月払い25ドル、年払いでは月換算20ドルです。

月25ドル分のCredit、最大2 Parallel Agents、Plan Mode、Unlimited Workspaces、AI Integrations、Replit branding削除などが含まれます。

Proは月払い100ドル、年払いでは月換算95ドルです。

月100ドル分のCredit、最大10 Parallel Agents、より強力なモデル、Premium Support、最大15 Collaborators、Database Rollback 28日などが含まれます。

Enterpriseは個別見積もりです。

ここで重要なのは、Subscription FeeだけでAgent利用量が固定されているわけではないことです。

Replit AgentはEffort-Based Pricingを採用しています。

簡単な変更は少ないCreditで済み、複雑なタスクはより多く消費します。

以前はCheckpointごとに固定0.25ドルという考え方でしたが、現在はAgentが使った計算量や作業量に応じてCredit消費が変わります。

公式の過去例では、簡単な依頼が0.06ドル相当から、複雑な依頼では1ドル以上になるケースも紹介されています。

そのためCoreの月25ドル分Creditを「100回Agentへ頼める」といった回数へ単純換算はできません。

アプリの規模、Chat History、Codebaseの大きさ、使うModeによって消費が変わります。

## CoreとProはどこで差が出る？

個人でWebアプリや小規模なサービスを作るなら、まずCoreで十分なケースが多いでしょう。

月25ドル分のCreditがあり、Parallel Agentも2つ使えます。Plan Modeも利用できるため、通常の開発には必要な機能が揃っています。

Proへ移る意味が出るのは、複数の大きな作業を同時に進めたい場合です。

Parallel Agentsが2から10へ増えるため、フロントエンド、バックエンド、テスト、デザインなどを並行して進められます。

月100ドル分Creditも含まれるため、Agentを毎日かなり使う人には余裕が出ます。

さらに強力なModel、Premium Support、Collaborator増加、長いDatabase Rollbackなど、商用サービス運用向けの機能もPro側です。

つまりProは「AIが少し賢くなるPlan」だけではありません。

**Agentへ任せる作業量と並列度を大きくし、複数人で本番アプリを継続開発するためのPlan**として考えた方が分かりやすいです。

## Replit Agentはどんな開発に向いている？

Replit Agentが向いているのは、アイデアからアプリ公開までを一つの環境で進めたい人です。

非エンジニアでもAgentに自然な言葉で作業を頼めますが、エンジニアにも使いやすい構成です。

AIが作ったコードを通常のIDEとして直接編集でき、Terminal、Database、Deployも同じWorkspaceにあります。

特に、AIだけで全部自動生成するより「大部分はAgentへ任せ、細かいところだけ自分でコードを触る」開発と相性があります。

LovableのようなAI App Builderと比べると、Replitはより一般的な開発環境としての性格が強いです。

既存コードを触る、Terminalを使う、複数言語を扱う、独自のバックエンド処理を書く、といった作業へ広げやすくなります。

一方、Webアプリを素早く作り、画面と機能を会話だけで完成させたい場合は、Lovableの方がシンプルに感じることもあります。

Replitを選ぶ基準は、**AIに作ってもらうだけでなく、必要になったら普通の開発環境として自分でも深く触りたいか**です。

## まとめ｜Replit AgentはAI開発と普通のプログラミングを同じ場所で続けたい人向け

Replit Agentは、自然な言葉からアプリを作り、Database、テスト、Deployまで進められるAI開発エージェントです。

Agent 4では複数Agentを並列で動かし、認証、バックエンド、デザインなどを同時に進められるようになっています。

Starterは無料、Coreは月25ドルまたは年払い月換算20ドル、Proは月100ドルまたは年払い月換算95ドルです。

Agentの利用はEffort-Based Pricingで、作業の複雑さによってCredit消費が変わります。

AI App Builderとして使い始めながら、必要になれば通常のIDE、Terminal、Database、Deployまで同じ環境で触れることがReplitの強みです。

開発を全部AIへ任せたい人だけでなく、AIと自分のコード編集を行き来しながら本番アプリを作りたい人ほどReplit Agentを使う意味が分かりやすくなります。
