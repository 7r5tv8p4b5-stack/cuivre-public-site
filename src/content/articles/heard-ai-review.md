# Heardとは？Claude Code・Codexの作業状況を音声で聞けるAI開発ツールを解説

※この記事の情報は2026年8月17日時点の公式情報・公開情報をもとに整理しています。

Claude CodeやCodexに作業を任せていると、

「終わったかな？」

「エラーで止まっていないかな？」

「何か判断を求められていないかな？」

と、結局ターミナルを何度も確認してしまうことがあります。

そんな**AIコーディングエージェントの作業状況を“耳で確認できる”ようにするツール**が「Heard」です。

HeardはClaude Code、Codex、Cursorなどの作業を監視し、進捗・エラー・判断が必要な場面などを、自然な音声による要約として伝えてくれます。

単純にターミナルの文字を読み上げるわけではありません。

**大量の出力から重要な情報を判断し、聞く価値のある内容だけを音声にする**ことがHeardの大きな特徴です。

2026年7月25日のProduct HuntではLaunch of the Dayを獲得しており、AIコーディングエージェントの普及とともに登場した新しいタイプの開発支援ツールとして注目されています。

この記事では、Heardで何ができるのか、Claude CodeやCodexでの利用、料金、対応OS、スマートフォン連携、SKIとの違いまで詳しく解説します。

## Heardの基本情報

| 項目 | 内容 |
|---|---|
| サービス名 | Heard |
| 主な用途 | AIコーディングエージェントの音声通知・操作 |
| 対応例 | Claude Code / Codex / Cursorなど |
| 対応OS | macOS |
| モバイル連携 | iPhone対応（Power） |
| Windows | 今後対応予定 |
| Android | 今後対応予定 |
| 無料プラン | あり |
| オープンソース | あり |
| 有料プラン | Pro / Power |

公式サイトではClaude Code、Codex、Cursorのほか、Ghostty、cmuxや通常のターミナルセッションなどにも対応すると案内されています。

## Heardとは？

Heardは、**AIコーディングエージェントの活動を音声で把握するためのボイスレイヤー**です。

たとえばCodexへ、

「この画面を修正して、最後にテストを実行して」

と依頼したとします。

Codexはその後、

ファイルを探す
↓
コードを変更する
↓
テストする
↓
問題を修正する
↓
作業を完了する

といった処理を進めます。

通常は、その状況を確認するために画面を見る必要があります。

Heardでは、この作業状況を分析し、

**何が進んだのか**

**何が失敗したのか**

**何について人間の判断が必要なのか**

といった重要な部分を音声で知らせます。

つまり、

**AIの出力を全部読み上げるツールではなく、AIの作業を音声で要約してくれるツール**

と考えると分かりやすいでしょう。

## Heardの面白さは「何を話さないか」にある

AIエージェントの出力をすべて音声にしたらどうなるでしょうか。

ファイル検索、コマンド、コード変更、テストログなどを延々と読み上げられることになります。

これでは実用的とは言えません。

Heardの開発者自身も、初期版ではすべてをナレーションすると短時間で耐えられなくなったと説明しています。

そこでHeardでは、**重要な情報を選別して話す**ことに重点が置かれています。

公式サイトでも、

- Progress
- Blockers
- Decisions
- Test results

などから必要な情報をまとめて伝える設計が紹介されています。

## 3つのListening Mode

Heardには、状況に応じて音声量を変えるモードがあります。

### Co-pilot

画面を見ながら作業しているときのモードです。

すべてを説明するのではなく、短い進捗や重要なポイントを音声で伝えます。

### Companion

画面から離れているとき向けです。

散歩、家事、休憩などをしながらでも状況を追えるよう、より詳しい説明を聞けます。

### Focus

基本的には静かにしておき、

**承認が必要**

**エラーが発生**

**作業が止まった**

**判断が必要**

といった場面だけ知らせるモードです。

AIへ長時間の作業を任せる場合には、特にこのFocusの考え方が便利そうです。

## Claude CodeやCodexに対応

HeardはClaude CodeとCodexを主要な対応対象としています。

公式サイトでは、

heard install codex

というCodex向けのセットアップ例も掲載されています。

Codexへ作業を任せて別のことをしていても、

「テストが通った」

「エラーが発生した」

「判断が必要になった」

といったタイミングを耳で把握できるわけです。

Claude Codeについても同様に、長時間動くエージェントセッションの進捗確認に利用できます。

## 複数のAIエージェントもまとめて把握できる

Heardがさらに面白いのは、**複数エージェントを並行して動かす環境**です。

Claude Codeを1つ、Codexを2つ……というように複数セッションを動かしていると、それぞれのターミナルを確認するだけでも大変になります。

Heardでは複数のセッションをまとめ、プロジェクトレベルで状況を把握できるよう設計されています。

公式サイトのMission Controlでも、複数セッションについて、

**Working**

**Ready**

**Needs you**

といった状態を一覧で確認するUIが紹介されています。

AIエージェントを並列実行する人ほど恩恵が大きくなりそうな機能です。

## iPhoneからAIエージェントへ返事もできる

Heardの上位機能「Power」では、MacとiPhoneをペアリングできます。

これによってMacの前から離れていても、

**AIの進捗を聞く**

だけでなく、

**AIへ音声で返事をする**

こともできます。

たとえばCodexが、

「この変更を進めていいですか？」

という判断待ちになった場合、iPhoneから返答して作業を継続させる使い方が想定されています。

公式サイトでは、スマートフォン側で追加アプリを必要としない利用方法も案内されています。

これは単なる「音声通知」から一段進んだ機能です。

## Heardは無料？

無料で利用できるFreeプランがあります。

2026年8月17日時点の公式料金は、月払い表示では次のようになっています。

| プラン | 月額 | 主な用途 |
|---|---:|---|
| Free | $0 | ローカル音声でエージェントを聞く |
| Pro | $15/月 | 管理された音声・ダッシュボードなど |
| Power | $30/月 | iPhone連携・双方向音声操作など |

また、公式サイトでは年間契約を選ぶと割引される料金体系も案内されています。

### Free

無料プランでは、

- ローカル実行
- Claude Code / Codex / Cursorなどへの対応
- 複数エージェントセッション
- ローカルKokoro音声
- 自分のAI・音声APIキーの利用
- 進捗・ブロッカー・テスト結果の音声通知
- オープンソース版

などが利用できます。

### Pro

Proでは管理された音声やLLMを利用でき、自分でAPIなどを細かく設定する手間を減らせます。

さらに、

- プレミアム音声・persona
- Mac間の履歴同期
- Agent View
- Dashboard View
- エージェント横断の日次音声サマリー

などが追加されます。

### Power

PowerではProの機能に加えて、

- iPhoneとのペアリング
- 双方向会話
- スマートフォンからPush-to-Talk
- 外出中の音声返信
- 適切なAIエージェントへの返信振り分け

などが利用できます。

公式サイトでは、ダウンロード時にカード登録不要の**14日間Powerトライアル**が付くと案内されています。

## オープンソース版もある

Heardにはオープンソース版があります。

自分のAPIキーを利用してセルフホストすることもでき、音声にはローカルで動作するKokoroを利用できます。

ライセンスはApache 2.0です。

そのため、

「AI開発中の情報をできるだけ自分の環境で扱いたい」

という開発者にとっても選択肢になります。

## プライバシーは？

Heard公式は、ローカルデスクトップワークフローを優先した設計だと説明しています。

FreeプランではローカルKokoro音声を利用でき、自分のAI・音声キーを使用することも可能です。

また公式FAQでは、**ユーザーのコードやプライベートな作業をモデル学習へ利用せず、データを販売しない**と明記されています。

ただしProやPowerではクラウド同期や管理された音声などのクラウド機能も利用します。

そのため、

**完全ローカルで利用する場合**

と

**クラウド機能を利用する場合**

は分けて考える必要があります。

## Heardの対応OS

2026年8月17日時点では、デスクトップ版の中心は**macOS**です。

公式サイトでは管理プランについてmacOS 13以降を案内しています。

PowerではiPhoneとの連携にも対応しています。

一方、

**Windows**

**Android**

については公式サイトで「coming soon」と案内されています。

現時点ではMacユーザー向けのサービスと考えるのがよいでしょう。

## Heardの始め方

基本的な流れはシンプルです。

1. HeardをMacへダウンロード
2. インストールしてメニューバーから起動
3. 音声やpersonaを選択
4. Listening Modeを選択
5. Claude CodeやCodexを接続
6. 普段どおりAIエージェントを使う

公式サイトでは数分でセットアップできると案内されています。

オープンソース版を自分で構築する方法も用意されています。

## HeardとSKIの違いは？

SKIの記事を読んだ人が特に気になるのがここでしょう。

どちらもClaude CodeやCodexと「音声」を組み合わせるサービスですが、中心となる考え方が少し違います。

| | SKI | Heard |
|---|---|---|
| 中心機能 | AIへ音声で指示 | AIの作業を音声で把握 |
| 人間 → AI | 強い | Powerでは対応 |
| AI → 人間 | 対応 | 特に強い |
| 複数Agent監視 | ― | 強い |
| スマホ連携 | ― | PowerでiPhone対応 |
| オープンソース | ― | あり |
| 主なデスクトップ環境 | macOS / Windows | macOS |

SKIは、

**「AIへ話しかける」**

ことから始まるツールです。

対してHeardは、

**「AIが何をしているのか聞く」**

ところから始まっています。

ただし現在のHeard PowerではAIへ音声で返答する機能まで提供されているため、両者の機能領域は一部重なっています。

SKIについて詳しく知りたい場合は、既存の[SKI解説記事](/articles/ski-ai-review/)も参照してください。

## Heardのメリット

### ターミナルを監視し続けなくていい

最大のメリットです。

AIエージェントが作業している数分〜数十分を、画面を見ながら待つ必要を減らせます。

### エラーや判断待ちを音声で把握できる

Focusのように、重要な場面だけ知らせる使い方ができます。

「いつの間にかAIが止まっていた」という時間を減らせる可能性があります。

### 複数エージェントとの相性がいい

Claude CodeやCodexを並列実行するほど、すべての画面を監視するのは難しくなります。

Heardは複数セッションをまとめて状況把握できるよう設計されています。

### 無料＋オープンソースから試せる

Freeプランがあり、セルフホスト可能なオープンソース版も用意されています。

いきなり有料契約する必要はありません。

## Heardの注意点

### 現在はMac中心

Windows版は今後対応予定です。

Windows中心の開発環境では、現時点では使いづらいでしょう。

### 高度な機能は有料

ローカル音声通知は無料で利用できますが、管理された音声や高度なダッシュボード、iPhoneからの双方向操作などはPro/Powerの領域です。

### 新しいサービスなので仕様変更の可能性がある

Heardは2026年に登場した新しいサービスです。

Product Huntでは2026年7月25日のLaunch of the Dayを獲得していますが、料金・対応OS・機能などは今後変化する可能性があります。

## Heardはどんな人に向いている？

特に相性がいいのは、

- Claude Codeを長時間動かす
- Codexへまとまった実装を任せる
- 複数のAIエージェントを同時に使う
- AIの処理中に別の仕事をしたい
- 何度もターミナルを確認している
- エラーや承認待ちだけ知りたい
- Macをメインで使っている
- AIエージェントをスマホから操作したい

という人です。

逆に、AIエージェントへ短い処理しか任せない人なら、音声で進捗を受け取るメリットは小さくなるでしょう。

## Heardについてよくある質問

### Heardは無料ですか？

Freeプランがあります。

ローカルKokoro音声、自分のAPIキー、複数のエージェントセッションなどを無料で利用できます。

### Codexに対応していますか？

はい。

Codexは公式に主要対応ツールとして案内されています。

### Claude Codeに対応していますか？

対応しています。

Claude CodeもHeardの中心的な対応エージェントです。

### Cursorでも使えますか？

公式サイトではCursorへの対応も案内されています。

### Windowsで使えますか？

2026年8月17日時点ではmacOSが中心で、Windowsは今後対応予定です。

### iPhoneから使えますか？

PowerプランではMacとiPhoneをペアリングし、エージェントの状況を聞いたり、音声で返答したりできます。

### オープンソースですか？

はい。

Heardはオープンソース版を公開しており、自分の環境で実行することもできます。

AIエージェントの進捗監視だけでなく、生成されたコード自体をAIでレビューしたい場合は[CodeRabbit](/articles/coderabbit-review/)も選択肢になります。

## まとめ｜Heardは「AIの作業を見張る時間」を減らすツール

Claude CodeやCodexによって、コードを書く作業そのものはAIへ任せられるようになってきました。

ところが次に生まれたのが、

**「AIが何をしているのか確認するために画面を見続ける」**

という新しい待ち時間です。

Heardは、そこを音声に置き換えようとしています。

**AIへ仕事を任せる  
↓  
人間は別のことをする  
↓  
重要な進捗だけHeardから聞く  
↓  
必要なときだけ判断する**

という働き方です。

さらにPowerではiPhoneからAIへ返答するところまで踏み込んでいます。

AIコーディングエージェントを1つ使うだけなら小さな便利ツールかもしれません。

しかしClaude CodeやCodexを複数並列で動かすようになるほど、**「AIをどう監督するか」そのものが新しい課題**になります。

Heardは、その問題に「音声」という方法で答えようとしている新しいサービスです。

Claude CodeやCodexへ長い作業を任せることが増えてきた人なら、無料版から試してみる価値があるでしょう。
