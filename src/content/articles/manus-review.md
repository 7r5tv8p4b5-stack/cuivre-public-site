# Manusとは？AIエージェントの使い方・料金・無料版でどこまでできるかを解説

Manusは、質問に答えるだけでなく、調査、Web操作、ファイル作成、スライド生成、Webサイト制作など、依頼した仕事を複数の手順に分けて実行できるAIエージェントです。

一般的なAIチャットでは、回答を受け取ったあとに人間が次の作業へ移る場面が多くあります。ManusのAgent Modeは、その「次に何をするか」まで考え、必要に応じてブラウザやクラウド上の実行環境を使いながら成果物を作るところまで進めるのが特徴です。

一方、現在のManusには通常の会話や質問へ素早く答えるChat Modeもあり、すべての依頼で重いAgent処理を使う必要はありません。

この記事では、2026年8月24日時点のManus公式情報をもとに、ManusがどんなAIなのか、Chat ModeとAgent Modeをどう使い分けるのか、無料版とProの差、クレジットがどのように消費されるのかまで整理します。

## Manusはどんなサービス？

Manusを理解するときは、まず「AIチャット」と「AIエージェント」の違いを見ると分かりやすいです。

Chat Modeでは、普通のAIチャットと同じように質問や相談ができます。画像、PDF、テキストファイルを読み取ったり、オンライン検索を使って回答したりすることもできます。

現在のManusでは、このChat Modeはクレジットを消費しません。

一方のAgent Modeは、回答文を返すだけではなく、依頼を完了するために実際の作業を進めます。

たとえば「このテーマを調査してレポートにして」と頼んだ場合、必要な情報を探し、内容を整理し、ファイルとしてまとめるところまで進められます。

Webサイトやスライド、動画などの制作にも対応しており、単純な文章生成より「完成物を作る」方向へ強いのがManusです。

そのためManusは、ChatGPTのようなAIへ質問する感覚だけで使うと少し特徴が見えにくくなります。

本来の価値は、**人間が途中でブラウザを開いたり、情報をCopyしたり、別のToolへ移したりしていた作業を、一つのTaskとしてAIへ渡せること**にあります。

Agent Modeでは、クラウド上の仮想マシン、ブラウザ自動化、コード実行、外部APIなどを使ってTaskを処理します。

つまりManusは「何をすればいいか教えてくれるAI」というより、「目的を伝えると、その目的を達成するための作業工程まで進めるAI」に近いサービスです。

## Chat ModeとAgent Modeはどう使い分ける？

すべての質問をAgent Modeへ投げる必要はありません。

「この文章を分かりやすくして」「アイデアを10個出して」「このPDFの内容について質問したい」といった依頼ならChat Modeで十分です。

Chat Modeはクレジットを消費しないため、日常的な相談やBrainstormingはこちらへ寄せた方が効率的です。

Agent Modeを使う意味が出るのは、答えを知りたいのではなく、作業そのものを終わらせたいときです。

たとえば複数のWebサイトを調べて比較資料を作る、Presentationを生成する、Webサイトを構築する、といったTaskです。

有料UserではWide Researchも利用できます。

これは複雑な調査Taskを複数のSubtaskへ分解し、並列で進める機能です。Userが毎回Buttonを押して起動するのではなく、Manusが「このTaskは分割した方がよい」と判断した場合に自動でTriggerされます。

一つのAgentが順番に100件調べるより、複数のSub-agentへ分けて並行処理するイメージです。

大量の商品、企業、候補、論文などを同じ基準で調査したいときに向いています。

普段はChat Mode、実作業を任せたいときにAgent Mode、さらに大量・並列調査ではWide Researchというように、依頼の重さで使い分けるとManusのクレジットも無駄になりにくくなります。

## Manusはどうやって使う？

ManusはWeb版から利用できます。

Accountを作成してTaskを入力し、軽い質問ならChat Mode、作業を実行してほしい場合はAgent Modeを使います。

Free UserはAgent ModeでManus 1.6 Liteを利用できます。

ProではManus 1.6 Liteに加えてManus 1.6とManus 1.6 Maxを利用でき、より複雑なTaskへ対応できます。

ManusにはDesktop Appもあります。

Desktop Appだから別の契約や専用クレジットが必要になるわけではありません。Web版と同じManus Accountへ紐づき、クレジット残高も共通です。

AppをInstallしただけ、あるいはBackgroundで起動しているだけではクレジットは消費されません。

実際にManus AgentがTaskを処理している間だけクレジットが使われます。

使い始めるときは、最初から「会社を全部調査して100枚の資料にして」のような巨大Taskを投げるより、小さなTaskでManusがどの程度まで自律的に進めるか確認した方が分かりやすいです。

たとえば「このテーマを調査して5項目に整理して」「この内容を5枚のSlideにして」といったTaskから始めれば、Agent ModeとChat Modeの違いも把握しやすくなります。

## Manusの料金について

ManusにはFree、Pro、Teamがあります。

Freeは0ドルです。

新規登録時には1,000 Creditsが付与され、その後は300 Daily Creditsが毎日Refreshされます。

ただしFree UserのDaily Refresh Creditsには月間1,500 Creditsの消費上限があります。またDaily CreditsはManus 1.6 Liteでのみ利用できます。

FreeではAgent Modeの同時実行Taskは1つ、Scheduled Taskは2つです。

Chat ModeはFreeでも利用でき、Chat Mode自体はクレジットを消費しません。

Proは月20ドルからです。

最初のPro Tierでは月4,000 Creditsから利用でき、Manus 1.6 LiteだけでなくManus 1.6、Manus 1.6 MaxへAccessできます。

Advanced Research、Professional Website Deployment、Slide Generation、Wide Researchなども有料User向け機能です。

同時実行Taskは20、Scheduled Taskも20まで増えます。

さらに月40ドルからのPro Tierもあり、月8,000 Creditsから利用できます。こちらには7日間のFree Trialも案内されています。

年間契約では月払いより17％安くなります。

Teamは複数人でManusを利用する組織向けPlanです。

個人で使う場合は、まずFreeでAgent Modeを試し、Task量や利用Modelが足りなくなった段階でProを見るのが自然です。

## Manusのクレジットは何に使われる？

Manusの料金で少し分かりにくいのがCreditsです。

「1回質問したら何Credit」という固定料金ではありません。

AgentがTaskを処理するときに使うLLM Token、仮想マシン、ブラウザ自動化、コード実行、第三者APIなどに応じてCreditsが消費されます。

そのため同じ1Taskでも、短い処理と長時間のResearchでは消費量が変わります。

Creditsが使われるのはActiveなTask Processing中だけです。

Taskが完成したあとにOutputを保存しているだけならCreditsは消費されません。Deployment済みの成果物を保持していること自体でもCredit消費はありません。

Manus側の技術的な問題でTaskが失敗した場合は、消費されたCreditsを全額Refundすると案内されています。

月間CreditsはSubscription開始日を基準に毎月Refreshされ、前Cycleで使わなかった月間Creditsは次へそのまま持ち越される仕組みではありません。

追加購入したAdd-on Creditsは、有効な有料Subscriptionを維持している間は次CycleへCarry Overできます。

この仕組みを見ると、Manusでは「月4,000 Creditsだから何回使える」と単純に計算するのが難しいことが分かります。

軽い質問をChat Modeへ寄せ、Agent Modeは実作業が必要なTaskに使う方がCredit効率はよくなります。

## 無料版でどこまで試せる？

Manusが自分に合うか確認するだけならFreeから始められます。

Chat Modeはクレジットを消費しないため、通常のAIとして質問したり、PDFを読ませたり、Web検索を使った回答を試したりできます。

Agent ModeもManus 1.6 Liteで利用できます。

同時Taskは1つですが、「Agentが自分で作業を進める」というManusの基本体験は確認できます。

Freeで先に問題になりやすいのは、ModelよりCreditsとTask量です。

Agentへ複雑なResearchや制作を何度も任せると、Daily Creditsだけでは作業を続けにくくなります。

またWide Researchや高度なModelを使いたい場合もProが必要です。

そのためProへ移る意味が出るのは、「Manusが便利そうだから」ではなく、**Agent Modeへ実際の仕事を継続して任せるようになったとき**です。

月に数回だけ軽いTaskを試すならFreeで十分な可能性があります。

毎週Research Reportを作る、Presentationを作る、Web制作を任せる、大量の候補をWide Researchで調査するといった使い方になるとProのCreditと機能が必要になります。

## Manusはどんな仕事に向いている？

Manusが向いているのは、AIの回答を受け取ったあとに人間が何工程も作業している仕事です。

Researchは分かりやすい例です。

通常なら検索→複数Pageを読む→情報を整理→表にする→Reportを書く、という工程があります。

Manusならこれらを一つのTaskとして渡せます。

PresentationやWeb制作でも同じです。

「構成案を出して」で終わらず、SlideやSiteという成果物まで作らせたい場合にAgent Modeの意味が出ます。

一方、文章の相談、翻訳、ちょっとした質問だけならManus Agentを使う必要はありません。

Chat Modeで十分ですし、すでに別のAI Chatを使っているなら、Manusを追加する理由も小さくなります。

Manusを選ぶ基準は、AIの回答品質だけを比べることではありません。

**自分がAIから回答を受け取ったあとに行っている作業まで、そのままTaskとして渡せるか**を見る方がManusの価値を判断しやすいです。

## まとめ｜Manusは「答えてもらう」より「仕事を終わらせてもらう」ときに価値が出る

Manusは、Chat Modeで質問へ答えるだけでなく、Agent ModeでResearch、Browser操作、File作成、Slide生成、Web制作などを実行できるAI Agentです。

FreeではChat ModeとManus 1.6 LiteのAgent Modeを試せ、新規登録時1,000 Credits、その後300 Daily Creditsが提供されます。

Proは月20ドルからで、月4,000 Credits、Manus 1.6 / 1.6 Max、Advanced Research、Wide Research、Slide Generationなどが利用できます。

軽い質問までAgentへ任せる必要はありません。

Chat ModeはCreditを消費しないため、相談はChat、成果物まで作ってほしい仕事はAgentと分ける方が合理的です。

Manusが必要になるのは「AIと会話したい人」より、調査や制作の途中工程を減らし、目的だけ伝えて仕事を最後まで進めたい人です。
