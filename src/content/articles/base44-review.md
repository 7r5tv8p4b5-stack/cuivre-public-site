# Base44とは？AIアプリ開発の使い方・料金・無料版でどこまで作れるかを解説

Base44は、作りたいアプリやWebサイトを普段の言葉で説明すると、AIがフロントエンドだけでなく、バックエンド、データベース、認証、決済までまとめて構築してくれるAI App Builderです。

完成したアプリは単なる画面サンプルではなく、そのまま本番環境で動かせます。Gmail、Slack、Notion、Google Drive、HubSpot、Salesforceなど外部サービスとの連携も用意されています。

この記事では、2026年8月24日時点のBase44公式情報をもとに、Base44がどんなサービスなのか、どうやってアプリを作るのか、Message CreditsとIntegration Creditsの違い、無料版からどのPlanへ上げる意味があるのかまで整理します。

## Base44はどんなサービス？

Base44は、アプリ開発で必要になる複数の仕組みを最初から一つにまとめたAI開発プラットフォームです。

AI App Builderには、画面を生成した後でDatabase、Login、Hostingなどを別サービスへ接続するものもあります。

Base44は、Backend、Database、Cloud Storage、User Authentication、Analytics、Marketing ToolなどをPlatform側に持っています。

そのため「顧客管理アプリを作って」と頼んだ後に、ユーザー登録、データ保存、管理画面などを追加しても、別のBackend Serviceを自分で契約しなくても進められます。

外部サービスとのIntegrationも特徴です。Gmailでメールを送る、Slackへ通知する、Google Driveから情報を取得する、HubSpotやSalesforceと顧客情報を連携するといった処理をアプリへ組み込めます。

一方、コードを触れない閉じたNo-code Serviceではありません。

Paid PlanではIn-app Code Editingを利用でき、Builder以上ではGitHub Integrationもあります。公式には作成したCode、Data、Usersを利用者が所有し、GitHubとの双方向同期でSource Codeを自分のRepositoryへ出せると説明しています。

Visual Editorもあり、生成された画面を見ながらResponsive Designを調整できます。

つまりBase44は、**AIに画面を作らせるだけでなく、アプリに必要なBackendまで標準装備し、外部連携を含めて本番公開へ持っていくNo-code寄りのAI App Builder**です。

## Base44ではどうやってアプリを作る？

最初は作りたいものを自然な言葉で説明します。

たとえば「小さな不動産会社向けに、顧客と内見予定を管理するアプリを作って」と入力し、必要な画面やデータを追加で伝えます。

Base44が初期アプリを生成したら、会話しながら修正します。「顧客ごとにメモを追加」「担当者別に絞り込み」「内見前日にメールを送信」といった形で機能を増やせます。

DatabaseやAuthenticationはPlatformに含まれているため、データを保存するアプリでも最初から動かせます。

外部サービスが必要ならIntegrationを追加します。たとえばGmail送信、Slack通知、LLM呼び出しなど、外部サービスを実行する処理ではIntegration Creditsを消費します。

完成したアプリはBase44上で公開できます。

独自Domainを使いたい場合はStarter以上、GitHubと同期して通常の開発フローへ持ち込みたい場合はBuilder以上が必要です。

このためBase44は、最初はNo-codeで作り、必要になったらCode / GitHubへ踏み込む段階的な使い方ができます。

## Base44の料金について

Base44にはFree、Starter、Builder、Pro、Eliteがあります。

Freeは0ドルです。月25 Message Creditsと100 Integration Creditsがあり、基本機能を使って実際にアプリを作成・公開できます。無料だから静的なDemoしか作れないわけではなく、AuthenticationやDatabaseも利用できます。

Starterは月払い20ドル、年払いでは月換算16ドルです。月100 Message Credits、2,000 Integration Credits。Unlimited Apps、In-app Code Editing、Custom Domainが利用できます。

Builderは月払い50ドル、年払いでは月換算40ドルです。月250 Message Credits、10,000 Integration Credits。AI Model Selection、GitHub Integrationなどが加わり、本格的な開発で使いやすくなります。

Proは月払い100ドル、年払いでは月換算80ドル。月500 Message Credits、20,000 Integration Creditsです。

Eliteは月払い200ドル、年払いでは月換算160ドル。月1,200 Message Credits、50,000 Integration Creditsに加え、Premium Supportなどが含まれます。

Enterpriseは個別見積もりです。年払いでは20%安くなります。

## Message CreditsとIntegration Creditsは何が違う？

Base44の料金を見るときは、この2種類のCreditを分けて考える必要があります。

Message Creditsは、主にBase44のAIへアプリ作成や修正を頼むための枠です。

「ログイン画面を追加」「このUIを修正」といったBuild中のAIとのやり取りで使います。実際の消費量はActionや選択したAI Modelによって変わります。

Integration Creditsは、作ったアプリが外部サービスを利用するときの枠です。

メール送信、画像生成、LLM RequestなどIntegrationを呼び出すActionで消費します。

アプリを完成させた後でも、利用者がAI機能や外部Integrationを使えばIntegration Creditsは減っていきます。

たとえばAI Chatbotを公開し、毎月多くのユーザーが質問するアプリなら、開発中のMessage Creditsより本番のIntegration Creditsの方が先に不足する可能性があります。

つまりPlanを選ぶときは「自分が何回AIへ修正を頼むか」だけではなく、**完成したアプリを利用者がどれくらい使うか**まで考える必要があります。

## 無料版からどのPlanへ上げる？

まずBase44を試すだけならFreeで十分です。

25 Message Creditsと100 Integration Creditsがあり、DatabaseやAuthenticationを含む実際のアプリを作れます。

ただしFreeはMessage Creditが少ないため、画面を何度も作り直す本格開発では早めに上限へ届きます。

最初の有料候補はStarterです。月払い20ドルでMessage Creditsが100、Integration Creditsが2,000へ増え、Custom DomainとCode Editingが使えます。

個人のMVPならStarterでもかなり進められます。

Builderへ上げる意味が出るのは、GitHub連携やAI Model Selectionが必要になったときです。Base44だけで完結せず、Source Codeを自分のRepositoryでも管理したいならBuilderが一つの境目です。

Pro / Eliteは、機能そのものよりCredit量の差が大きくなります。公開アプリの利用者が増え、AIや外部Integrationを大量に実行するようになった段階で検討するPlanです。

## Base44はどんな開発に向いている？

Base44が向いているのは、Backendを含むWebアプリをできるだけ少ない準備で作りたい人です。

顧客Portal、CRM、社内Tool、予約管理、SaaSのMVPなど、User AccountとDatabaseを持つアプリと相性があります。

特に非エンジニアにとって、Database、Authentication、Hostingを別々に理解しなくても始められることは大きなメリットです。

一方、開発者でも、最初のVersionを素早く作り、必要になったらGitHubへ移して通常開発へ広げる使い方ができます。

注意したいのは、公開後のIntegration Creditsです。AIを多用するサービスでは、開発が終わっても利用者のActionによってCreditが減ります。

Base44を選ぶ基準は、**AIによるコード生成だけでなく、Backend・Authentication・Database・外部Integrationまで最初からまとめて欲しいか**です。

## まとめ｜Base44はBackendまで含めてAIにアプリを組み立ててほしい人向け

Base44は、自然な言葉からフロントエンド、バックエンド、Database、Authentication、Paymentなどを含むWebアプリを構築できるAI Platformです。

Freeでも月25 Message Creditsと100 Integration Creditsがあり、本番環境で動くアプリを試せます。

Starterは月20ドル、Builderは50ドル、Proは100ドル、Eliteは200ドル。年払いならそれぞれ月換算16ドル、40ドル、80ドル、160ドルです。

開発中はMessage Credits、公開後に外部Serviceを動かすとIntegration Creditsを使うため、料金は「何回作り直すか」と「完成後に何回使われるか」の両方で考える必要があります。

画面だけでなくBackendまでまとめて作り、必要になったらCodeやGitHubへ移りたい人には使いやすいAI App Builderです。
