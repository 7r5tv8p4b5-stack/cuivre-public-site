# Read AIとは？使い方・料金・どんな人に向いているかをわかりやすく解説

Read AIは、ZoomやGoogle Meet、Microsoft Teamsなどの会議を記録し、文字起こしや要約、アクション項目の整理まで自動化できるAI会議アシスタントです。オンライン会議だけでなく、Windows・MacのデスクトップアプリやiPhone・Androidアプリを使って、対面の会話を記録することもできます。

AI議事録ツールは似たサービスが多いので、Read AIも「会議を文字起こしするだけのサービス」に見えやすいかもしれません。ただ、実際には会議後の要約やタスク整理だけでなく、過去の会議や連携した情報を検索する機能まで含まれていて、会議の記録をその後の仕事にどう使うかまで考えられています。

この記事では、2026年8月23日時点の公式情報をもとに、Read AIがどんなサービスなのか、どの端末でどう使うのか、料金はいくらなのか、そのうえでどんな使い方に向いているのかまで整理します。

## Read AIとはどんなサービス？

Read AIの基本は、会議にAIアシスタントを参加させて内容を記録し、終了後に文字起こしや要約を作る使い方です。Zoom、Google Meet、Microsoft Teamsに対応しており、カレンダーを連携しておけば、指定した会議へ自動的に参加させることもできます。

会議が終わると、全文の文字起こしだけでなく、重要なポイントや決定事項、アクション項目などが整理されたレポートを確認できます。誰が何を話したかを残すだけではなく、「次に何をするのか」まで拾いやすいので、議事録を作って終わりではなく、その後の仕事につなげやすいのが特徴です。

また、Read AIは会議中の発言時間やエンゲージメントなども分析します。単純な文字起こしだけを求める人には少し機能が多く感じるかもしれませんが、会議の内容だけでなく、進め方そのものを振り返りたいチームには使い道があります。

たとえば毎週同じメンバーで定例会議をしている場合、内容を記録するだけでなく、前回の決定事項や未完了の話題を探して次の会議につなげる使い方ができます。Read AIは、**一回の会議を文字にするためのサービスというより、会議で生まれた情報をあとから使いやすく残すサービス**と考えると分かりやすいです。

## Read AIはどうやって使う？

Read AIは、オンライン会議だけに使うサービスではありません。Web上のアカウントに加えて、Windows・Mac向けのデスクトップアプリ、iPhone・Android向けのモバイルアプリが用意されています。

オンライン会議では、Zoom、Google Meet、Microsoft TeamsにReadのアシスタントを参加させる方法が基本です。カレンダーを連携して自動参加させることもできますし、必要な会議だけ手動で追加することもできます。

WindowsとMacにはデスクトップアプリがあり、Windowsは64bit版のWindows 10・11、MacはmacOS 14 Sonoma以降に対応しています。デスクトップアプリでは、ReadのBotを会議へ参加させるだけでなく、パソコン上の音声を直接録音できます。ZoomやTeams以外の通話サービスを使っている場合でも、PCから流れる音声を記録するという使い方ができます。

スマートフォンでは、iPhoneはiOS 17.5以降、AndroidはAndroid 12以降に対応しています。モバイルアプリから対面の会議や会話をその場で録音し、文字起こしと要約を作成できます。スマホで記録した内容も同じアカウントで同期されるので、あとからパソコンで確認できます。

この構成なら、会社のオンライン会議はWindowsから記録し、外出先の打ち合わせはiPhoneで録音するといった使い分けができます。

ただし、ReadのAIアシスタントが直接参加できるオンライン会議はZoom、Google Meet、Microsoft Teamsが中心です。WebexやGoToMeetingなどではBotを直接参加させられないため、その場合はデスクトップアプリで音声を記録するか、あとから録音ファイルをアップロードする形になります。

普段使っている会議サービスが何かによって、最も使いやすい方法は少し変わります。

## Read AIの料金について

Read AIには無料プランがあり、クレジットカードを登録せずに始められます。無料プランでは月5回まで会議の文字起こしができ、要約や検索、会議分析などの基本機能も利用できます。

月5回という制限なので、Read AIが自分の会議でどの程度使えるか試すには十分です。一方で、毎週複数の会議を記録する人なら、比較的早い段階で上限に達します。

個人や小規模チーム向けのProは、年払いなら1ユーザーあたり月15ドル、月払いでは19.75ドルです。Proになると会議の文字起こしが無制限になり、Notion、Salesforce、HubSpot、Jira、Confluence、Zapierなどのプレミアム連携や、月100回分のファイルアップロード枠も追加されます。

そのため、有料にするタイミングは分かりやすいです。月に数回の重要な会議だけ記録するなら、まず無料プランで十分でしょう。逆に、毎週の定例会議や商談をほぼすべて残したいなら、月5回では足りないのでProへ移る意味が出てきます。

さらに上位のEnterpriseは年払いで月22.50ドル、Enterprise+は月29.75ドルです。Enterpriseでは動画再生やハイライトなどが加わり、Enterprise+ではデータ保持ポリシーやSAMLなど、組織向けのセキュリティ・管理機能が強化されます。

個人利用であれば、無料かProのどちらかを考えれば十分です。Enterprise以上は単純に「より便利な個人向けプラン」というより、会社としてRead AIを管理・運用するためのプランと考えた方が近いです。

## Read AIはどんな使い方に向いている？

Read AIが特に合うのは、会議の文字起こしだけでなく、**会議で出た情報をあとから何度も使う人**です。

たとえば営業チームなら、商談を記録して要約を残すだけでなく、「次回までに何をするのか」「顧客が何を気にしていたのか」をあとから確認できます。毎回メモを読み返したり、録音の該当部分を探したりするより、会議レポートから必要な情報を探せる方が仕事は進めやすくなります。

定例会議が多いチームでも使いやすいでしょう。前回の会議で決まったことを忘れたときに、過去のレポートや文字起こしを遡れるので、会議ごとの記録がばらばらになりにくくなります。Read AIは会議だけでなく、メールやメッセージングの情報も検索対象として扱う方向に広がっているため、「あの話はどこで決まったのか」を探す負担を減らしたい人には相性があります。

対面とオンラインの両方で打ち合わせがある人にも向いています。ZoomやTeamsではAIアシスタントを使い、客先での打ち合わせはスマホアプリで録音するという形なら、記録をRead AIへまとめられます。

一方で、月に数回しか会議をせず、必要なのも文字起こしだけという人なら、Read AIの機能をすべて使う必要はありません。会議分析や横断検索、各種連携まで使わないなら、よりシンプルな文字起こしサービスの方が分かりやすい場合もあります。

また、会議へAIアシスタントが参加する使い方では、相手側にもBotが表示されます。社外の商談や取材で使う場合は、録音やAIアシスタントの参加について相手に説明する必要がある場面も出てきます。

Read AIは、単に議事録を書く時間を短くしたい人にも使えますが、強みが出やすいのはその先です。**会議で生まれた情報を残し、次の仕事や別の会議でも再利用したい人ほど、Read AIを使う意味が大きくなります。**

## まとめ｜Read AIは会議の記録を「あとで使いたい人」に向いている

Read AIは、Zoom、Google Meet、Microsoft Teamsのオンライン会議を記録できるほか、Windows・MacのデスクトップアプリやiPhone・Androidアプリを使って対面の会話も残せます。オンラインと対面の両方を一つのサービスで管理できるので、働く場所や会議方法が一定でない人でも使いやすい構成です。

無料プランでは月5回まで会議を文字起こしできるため、まず自分の会議で精度や要約の内容を確認できます。そのまま月数回の利用で足りるなら無料で十分ですし、毎週の定例会議や商談を継続して記録したくなった段階でProを検討すればいいでしょう。

Read AIを選ぶ意味が特に大きいのは、文字起こしを作ること自体よりも、その記録をあとから探したり、決定事項やアクション項目を次の仕事につなげたりしたい場合です。

反対に、たまに録音を文字にするだけなら機能を持て余す可能性があります。会議が多く、その内容を毎回記録・整理・検索する手間が積み重なっている人ほど、Read AIの便利さを感じやすいサービスです。
