# SKIとは？Claude Code・Codexを音声操作できる無料AIツールの使い方を解説

※この記事の情報は2026年8月17日時点の公式情報・公開情報をもとに整理しています。

Claude CodeやCodexを使っていると、

「これ、キーボードで入力するより話したほうが早いのでは？」

と思うことがあります。

そんなAIコーディングエージェントとのやり取りを**音声中心に変えるデスクトップツール**が「SKI」です。

SKIでは、Claude CodeやCodexなどへ声で指示を送り、処理結果についてAIから音声で返答を受けられます。

単純な音声入力ツールではなく、

**人間が話す → AIエージェントが作業する → AIが音声で結果を伝える**

という双方向のやり取りを目指しているのが大きな特徴です。

2026年7月30日にProduct Huntへ登場し、その日のランキングで1位を獲得。まだ登場したばかりの新しいサービスですが、Claude CodeやCodexを日常的に利用する人なら注目しておきたいツールです。

この記事では、SKIでできること、対応するAIコーディングエージェント、料金、インストール方法、注意点などをまとめます。

## SKIの基本情報

| 項目 | 内容 |
|---|---|
| サービス名 | SKI |
| 主な用途 | AIコーディングエージェントの音声操作 |
| 対応例 | Claude Code / Codex / Cursor / Gemini CLIなど |
| 対応OS | macOS / Windows |
| macOS要件 | macOS 14.4 Sonoma以降・Apple Silicon M1以降 |
| Windows要件 | Windows 10 / 11 |
| 音声処理 | ローカル処理 |
| ローカル機能 | 無料 |
| クラウド機能 | 一部有料機能あり |
| Linux | 開発側が今後の対応予定を案内 |

公式リリース情報では、Claude Code、Cursor、Codex、Gemini CLIなどへの対応が案内されています。

## SKIとは？

SKIは、AIコーディングエージェントと**声で会話しながら開発するためのツール**です。

たとえばCodexを使っているとします。

通常なら、

「この画面のレイアウトを変更して。既存のロジックには触れず、モバイル表示だけ修正して」

とキーボードで入力します。

SKIを使えば、こうした指示を声で伝えられます。

さらに特徴的なのが、その逆方向です。

作業が終わったとき、エージェント側からも音声で結果を返せます。

長いコードをそのまま読み上げるという意味ではありません。開発者の説明では、たとえば大量のコードを書いた場合でも、エージェント側が「作業が完了した」といった要点を音声で伝える使い方が想定されています。

つまりSKIが目指しているのは、

**音声入力ソフト**

というより、

**AIコーディングエージェントとの音声インターフェース**

に近いものです。

## SKIでできること

### Claude CodeやCodexへ声で指示する

SKIの中心機能です。

MacではFunctionキーを押しながら話すなど、Push-to-Talk方式でエージェントへ指示できます。ホットキーについては設定から変更することもできます。

長いプロンプトをキーボードで入力する代わりに、そのまま話せるのがメリットです。

特に、

「ここをこう変更して、そのあとこのファイルも確認して……」

といった自然言語による長めの指示との相性がよさそうです。

### AIから音声で返答を受ける

SKIは音声をテキストに変換するだけではありません。

エージェント側から音声で返答させられるのが特徴です。

これによって、

**指示 → 作業 → 完了報告**

まで、画面をずっと見続けなくても進められる可能性があります。

### 複数のエージェントを扱う

SKIは特定のAIコーディングツールだけに限定されたものではありません。

公式リリース情報では、

- Claude Code
- Cursor
- Codex
- Gemini CLI

などが案内されています。

Product Hunt上では、ほかのエージェントについても対応表示があることがユーザーから指摘されており、対応範囲は今後変わる可能性があります。

### 音声を確認してから送信する

音声操作で気になるのが誤認識です。

特にプログラミングでは、ファイル名や技術用語などを間違えて認識される可能性があります。

SKIには、文字起こしされた内容を**送信前に確認・編集するオプション**があります。

音声だけですべてを確定させる必要はなく、

**話す → 文字起こしを見る → 必要なら直す → AIへ送る**

という使い方もできます。

### スクリーンショットも使える

音声だけでは説明しづらい場面もあります。

たとえば、

「このボタンをもう少し右へ」

と言っても、AI側が「このボタン」を理解できなければ困ります。

開発者の説明では、SKIからスクリーンショットをエージェントへ渡したり、画面を参照させたりする使い方ができます。

UIを見ながら、

**「ここの余白を直して」**

と話すような使い方との相性がよさそうです。

### Silent Modeもある

音声で返事をしてほしくない場面ではSilent Modeを利用できます。

AIが話している途中でも音声を止め、テキスト中心のやり取りへ切り替えることができます。

常に音声を使うのではなく、状況によって切り替えられるのは実用的です。

## SKIの特徴は「音声入力」だけではない

SKIを理解するうえで重要なのが、一般的な音声入力ツールとの違いです。

音声入力ツールなら、

**声 → テキスト**

で役割は終わります。

SKIの場合は、

**声 → AIへの指示 → AIが作業 → 音声で報告**

までを一つの流れとして扱います。

Claude CodeやCodexのような自律的に作業するAIエージェントが普及してきたからこそ成立するタイプのツールと言えるでしょう。

## SKIは無料？

2026年8月17日時点では、**ローカルで動作するSKIの主要機能は無料**と案内されています。

カード情報なども必要なく、ローカル機能について開発者は無料で提供すると説明しています。

ただし、「SKIはすべて完全無料」と理解するのは正確ではありません。

後述するクラウドを利用する一部機能では料金が発生する場合があります。

## 会議にAIエージェントを参加させる機能もある

SKIにはかなり変わった機能があります。

AIエージェントをオンライン会議へ参加させる機能です。

開発チームは、SKIを使ってコーディングセッションを会議へ持ち込み、その場で作業させたり、エージェントを参加者として会議へ送ったりする用途を紹介しています。

一方、この機能はローカルだけでは完結しません。

Product Huntで開発者は、クラウドエージェント機能はクラウドインフラを利用するため、無料クレジットを消費し、その後は必要に応じてクレジットを追加する仕組みだと説明しています。

したがって、

**通常のローカル音声コーディング → 無料**

**クラウドを利用してエージェントを会議へ参加させる → 無料枠後は有料の場合あり**

と分けて理解するのがよさそうです。

## SKIはプライバシー面も特徴

音声を使うサービスでは、

「自分が話した内容がクラウドへ送られるのでは？」

と気になる人もいるでしょう。

SKIの公式リリースページでは、Speech-to-Textと音声出力の両方を端末上で処理し、ユーザーの音声をアップロードしないと説明しています。

Product Huntでも開発者は、音声入力と音声出力がローカルで動作し、オフラインでも利用できると説明しています。

ただし、前述したクラウド会議機能などは別です。

**ローカル音声機能とクラウド機能を分けて考える**必要があります。

## SKIの対応OS

2026年8月17日時点で、公式リリースページからMac版とWindows版を入手できます。

### Mac

要件は、

**macOS 14.4（Sonoma）以降**

かつ、

**Apple Silicon M1以降**

です。

Intel Macについては公式ダウンロード要件に含まれていません。

### Windows

Windows版は、

**Windows 10 / Windows 11**

に対応しています。公式リリースページではx64 / ARMが記載されています。

ただし注意点があります。

2026年8月17日時点ではWindows版はまだコード署名されていないため、**初回インストール時にWindowsから警告が表示される可能性があります。**

公式側もこの点を明記しています。

一方、自動アップデートについては暗号学的に署名・検証すると説明されています。

### Linux

Product Huntで開発者はLinux版について「次」と案内していますが、2026年8月17日時点の公式リリースリポジトリではMac/Windows向けの配布が中心です。

現時点ではMacまたはWindowsユーザー向けと考えたほうがいいでしょう。

## SKIのインストール方法

SKIは公式サイトから入手できます。

SKI公式サイト:
https://heyski.io/

公式リリース:
https://github.com/pattern-ai-labs/ski-releases

基本的な流れは、

1. SKIをダウンロード
2. アプリをインストール
3. マイクなどの権限を設定
4. 使用するAIコーディングエージェント向けにSKI Skillを設定
5. SKIから音声でエージェントへ指示

となります。

公式リリースページでは、アプリ本体がウィジェット部分を提供し、AIエージェント側に「耳と声」を持たせる役割をSKI Skillが担うと説明されています。

そのため、単にアプリをインストールするだけでなく、**利用するエージェント側のSKI設定も必要**になる点は覚えておきましょう。

## Codexでも使える？

使えます。

公式リリース情報でCodexは対応対象として明記されています。

つまり普段Codexへキーボードで長い指示を書いている部分を、SKIを使って音声化できる可能性があります。

たとえば、

「既存のレイアウトには触らず、このコンポーネントだけ修正して。終わったらbuildしてエラーがあれば原因を教えて」

といった指示を声で伝えるイメージです。

特にAIエージェントへ自然言語で長い作業指示を出す人ほど、SKIのメリットを感じやすそうです。

## Claude Codeでも使える？

Claude Codeも主要な対応対象です。

Claude Codeで、

- 実装を依頼する
- 修正を指示する
- 状況を聞く
- 完了報告を受ける

といったやり取りを音声化できます。

## 日本語でも使える？

ここは注意が必要です。

2026年8月17日時点で確認した公式リリース情報やProduct Huntの説明では、**日本語について明確に対応言語として保証する記載を確認できませんでした。**

そのため、現段階でCuivreから「日本語完全対応」と断定するのは避けます。

日本語利用を考えている人は、実際の環境で音声認識精度を確認してから本格利用するのがよいでしょう。

## SKIのメリット

### 長い指示を話して伝えられる

AIコーディングエージェントへの指示は、通常の検索より長くなりがちです。

数行のプロンプトを何度も入力する人なら、音声化による時間短縮を期待できます。

### 作業完了を音声で受け取れる

SKIの面白さは入力だけではありません。

AI側から音声で状況を返せるため、画面を常に確認する必要を減らせる可能性があります。

### Claude Codeだけに限定されない

Codex、Cursor、Gemini CLIなど複数のエージェントへの対応が案内されています。

AIコーディング環境を変更しても使い続けられる可能性があるのはメリットです。

### ローカル音声処理

音声をクラウドへ送らず端末上で処理する設計は、開発内容を音声で話すツールとして重要なポイントです。

## SKIの注意点

### まだ登場したばかり

SKIは2026年7月30日にProduct Huntへ登場した非常に新しいサービスです。

今後、

- 対応エージェント
- UI
- 料金
- OS対応
- 機能

などが変わる可能性があります。

### Windowsでは初回警告の可能性

Windows版は2026年8月17日時点でコード署名されていないため、初回インストール時にSmartScreenなどの警告が出る可能性があります。

### 音声出力先をアプリ内で選べない

Product Huntでは、複数のマイク・スピーカーを使っているユーザーから入出力先について要望が出ています。

開発者によるとマイク入力はPreferencesから選択できますが、**アプリ内で音声出力先を選択する機能は現時点ではありません。**

今後のアップデートで対応する意向が示されています。

### すべての機能が無料ではない

ローカル機能は無料ですが、クラウドインフラを使う会議参加機能などには有料部分があります。

「SKI＝すべて完全無料」と考えないほうがいいでしょう。

## 実際の反応は？

まだ登場直後なので、長期利用レビューが十分に蓄積している段階ではありません。

一方、Product Huntでは2026年7月30日のLaunch of the Day #1となり、その週のランキングでも4位に入っています。

ユーザーからは音声入出力先の選択、料金表示の分かりやすさ、騒音環境での利用、AIが話している途中の操作など、かなり具体的な質問・要望も出ています。

現時点では「評価が固まったサービス」というより、**ローンチ直後に注目を集め、実利用者から改善要望が出始めている段階**と見るのが適切です。

## SKIが向いている人

特に相性がよさそうなのは、

- Claude Codeを頻繁に使う
- Codexへ長い指示を出す
- AIエージェントへの入力を高速化したい
- キーボード入力を減らしたい
- 複数のAIコーディングエージェントを使う
- AIから作業完了を音声で受け取りたい
- 音声データをできるだけローカルで処理したい

という人です。

逆に、AIへ短い指示しか出さない人や、職場などで声を出しにくい環境ではメリットを感じにくい可能性があります。

## SKIについてよくある質問

### SKIは無料ですか？

ローカルで動作する主要機能は無料と案内されています。

ただしクラウドインフラを利用する一部機能には有料部分があります。

### Codexに対応していますか？

はい。公式リリース情報でCodexへの対応が明記されています。

### Claude Codeに対応していますか？

はい。Claude CodeはSKIの主要な対応エージェントです。

### Cursorでも使えますか？

公式リリース情報ではCursorも対応対象として案内されています。

### Macで使えますか？

利用できます。

2026年8月17日時点の要件はmacOS 14.4 Sonoma以降、Apple Silicon M1以降です。

### Windowsで使えますか？

Windows 10 / 11向けの公式配布があります。

ただし現時点ではWindows版がコード署名されていないため、初回インストール時に警告が表示される可能性があります。

### Linuxで使えますか？

2026年8月17日時点では公式リリースページの配布対象はMacとWindowsです。

開発者はLinux対応を今後の予定として案内しています。

### 日本語で使えますか？

今回確認した公式情報では、日本語への正式対応を明確に保証する記載は確認できませんでした。

日本語音声で使いたい場合は、実際の環境で認識精度を確認することをおすすめします。

## まとめ｜SKIは「AIと話しながらコードを書く」を現実的にする新しいツール

SKIは、Claude CodeやCodexなどのAIコーディングエージェントを音声操作するための新しいデスクトップツールです。

ポイントは、単なる音声入力ではありません。

**話して指示する  
↓  
AIエージェントが作業する  
↓  
AIが音声で結果を返す**

という双方向の体験を作ろうとしています。

ローカル音声処理、複数のAIエージェントへの対応、送信前の文字起こし確認、スクリーンショット、Silent Modeなど、実際のコーディングを意識した機能も用意されています。

一方で、2026年7月に登場したばかりなので、Windows版のコード署名や音声出力先の選択、日本語対応の明確さなど、今後の改善を見たい部分もあります。

Claude CodeやCodexを毎日使っていて、**「AIへの指示をキーボードで打つ時間を減らしたい」**と感じているなら、試してみる価値のあるサービスでしょう。
